### 5. ขั้นตอนการตั้งค่าและทดสอบด้วย GX Works3 / GX Simulator3

1\. เปิด GX Works3 เลือก Project → New เลือก Series: FX5CPU, Type: FX5U,
Program Language: Ladder แล้วกด OK

2\. ที่ Navigation window เลือก Program → MAIN → Program Body
เพื่อเปิดหน้าจอแก้ไข Ladder

3\. วางหน้าสัมผัสและคอยล์ตามโปรแกรมในภาพที่ 1.L2 โดยพิมพ์ชื่ออุปกรณ์ X0, Y0 (ขนาน),
X1 (หน้าสัมผัส NC), Y0 (คอยล์) ตามลำดับ

4\. แปลงโปรแกรม (Convert, ปุ่ม F4) ตรวจว่าไม่มีข้อผิดพลาดในหน้าต่าง Output

5\. เริ่มการจำลอง (Debug → Simulation → Start Simulation) เพื่อเปิด GX
Simulator3 และเขียนโปรแกรมลงตัวจำลอง ตรวจว่า CPU อยู่ในสถานะ RUN
(ชื่อเมนู/ปุ่มลัดอาจต่างตามเวอร์ชัน)

6\. ใช้ Watch window ลงทะเบียน X0, X1, Y0 แล้วสลับค่า X0, X1 (ON/OFF)
ตามตารางที่ 1.L2 พร้อมสังเกตและบันทึกค่า Y0

7\. หากมีชุดฝึกจริง: ต่อสาย Ethernet ตั้งค่า Connection Destination แล้ว Online →
Write to PLC ตั้ง CPU เป็น RUN และทดสอบด้วยปุ่มกดจริง (หลังผู้สอนตรวจวงจร)

### คำถามท้ายการทดลอง/การปฏิบัติ

1\. เหตุใด Y0 จึงยังติดอยู่เมื่อปล่อยปุ่ม START? อธิบายโดยใช้หน้าสัมผัส Y0 และวงรอบสแกน

2\. หากเปลี่ยนปุ่ม STOP เป็นแบบ NC (ต่อจริง) ต้องปรับโปรแกรมอย่างไร
และเหตุใดวิธีนี้จึงปลอดภัยกว่าเมื่อสายขาด

3\. เมื่อกด START และ STOP พร้อมกัน Y0 เป็นอย่างไร
และแสดงว่าวงจรนี้ให้ความสำคัญกับปุ่มใด

4\. หากต้องการเพิ่มไฟแสดงสถานะ "หยุด" ที่ Y1 (ติดเมื่อ Y0 ดับ)
ต้องเพิ่มบรรทัดโปรแกรมอย่างไร
