### 1. จุดประสงค์การทดลอง/การปฏิบัติงาน

1\. เขียนโปรแกรม Self-holding แบบ Stop priority และ Interlock
เดินหน้า–ถอยหลังใน GX Works3 ได้

2\. เขียนวงจร Toggle ด้วย PLS และใช้ SET กับ ZRST ได้ถูกต้อง

3\. ทดสอบโปรแกรมด้วย GX Simulator3 และ/หรือ PLC FX5U จริง
และบันทึกผลตามลำดับการทดสอบได้

4\. ต่ออินพุตแบบ Sink (สวิตช์ NO) และเอาต์พุตทรานซิสเตอร์ (หลอดไฟ 24 VDC)
ได้อย่างถูกต้องและปลอดภัย

5\. วิเคราะห์ผลของลำดับแถวและ Double coil ต่อค่าเอาต์พุตได้

### 5. ขั้นตอนการตั้งค่าและทดสอบด้วย GX Works3 / GX Simulator3

1\. เปิด GX Works3 เลือก Project → New เลือก Series: FX5CPU, Type: FX5U,
Program Language: Ladder แล้วกด OK

2\. เปิด Program → MAIN → Program Body วางหน้าสัมผัสและคอยล์ของโปรแกรม 1
ตามภาพที่ 3.L2 แล้วใส่ END

3\. แปลงโปรแกรม (Convert, ปุ่ม F4) ตรวจว่าไม่มีข้อผิดพลาด

4\. เริ่มการจำลอง (Debug → Simulation → Start Simulation)
เขียนโปรแกรมลงตัวจำลองและตั้ง CPU เป็น RUN (ชื่อเมนูอาจต่างกันตามเวอร์ชัน)

5\. ลงทะเบียน X0–X2, Y0, Y1 ใน Watch window แล้วทดสอบตามตารางที่ 3.L2
พร้อมบันทึกผลทุกขั้น

6\. เปลี่ยนเป็นโปรแกรม 2 (ภาพที่ 3.L3) ลงทะเบียน X0–X2, M0, Y0, Y1
แล้วทดสอบตามตารางที่ 3.L3

7\. หากมีชุดฝึกจริง: ต่อสายตามภาพที่ 3.L1 ตั้งค่า Connection Destination, Online →
Write to PLC, ตั้ง CPU เป็น RUN แล้วทดสอบซ้ำ

8\. เสร็จแล้วถอดสายและเก็บอุปกรณ์ให้เรียบร้อย

### คำถามท้ายการทดลอง/การปฏิบัติ

1\. ผลที่วัดได้ตรงกับค่าคาดการณ์ทุกขั้นหรือไม่ หากไม่ตรงให้ระบุขั้นที่ผิดและสาเหตุ

2\. ในขั้นที่ 7 ของตารางที่ 3.L2 (กด SW0 และ SW1 พร้อมกัน) ทิศใดชนะ เพราะเหตุใด
และถ้าสลับลำดับแถว 0 กับ 1 ผลจะเปลี่ยนอย่างไร

3\. ถ้าเปลี่ยน SW2 (STOP) ให้ต่อแบบ NC จริง ต้องแก้โปรแกรม 1 อย่างไร
และข้อดีด้านความปลอดภัยคืออะไร

4\. ถ้าตัด PLS ออกและต่อ X0 เข้ากับสมการ Toggle โดยตรง ผลที่ Y0 ขณะกด SW0
ค้างเป็นอย่างไร เพราะเหตุใด

5\. ถ้ากด SW1 และ SW2 พร้อมกัน ผลที่ Y1 เป็นอย่างไรเมื่อแถว ZRST อยู่ท้ายโปรแกรม
และจะเปลี่ยนไปอย่างไรถ้าย้ายแถว ZRST ไปไว้ก่อนแถว SET

### ใบมอบงานหน่วยเรียนที่ 3

### จุดประสงค์เชิงพฤติกรรม

\- วิเคราะห์ระบบควบคุมจริง 1 ระบบ ระบุอินพุต เอาต์พุต และเงื่อนไขการทำงานได้

\- เขียนโปรแกรม Ladder และรายการคำสั่งด้วยคำสั่งพื้นฐานและตรวจสอบด้วยการจำลองได้

### หัวข้อการปฏิบัติงาน

"การออกแบบโปรแกรมควบคุมระบบขนาดเล็กด้วยคำสั่งพื้นฐานของ PLC" — เลือกระบบ 1 ระบบ
เช่น ปั๊มน้ำพร้อมสวิตช์ระดับ ประตูม้วนเปิด–ปิดที่ต้อง Interlock
หรือไฟทางเดินที่ควบคุมด้วยปุ่มเดียวแบบ Toggle ต้องใช้ Self-holding หรือ SET/RST
อย่างน้อย 1 จุด และมี Interlock หรือ PLS อย่างน้อย 1 จุด

### สื่อการเรียน เครื่องมือ อุปกรณ์

\- ใบความรู้หน่วยที่ 3 และคู่มือ FX5U

\- คอมพิวเตอร์ที่ติดตั้ง GX Works3 (ใช้ GX Simulator3 ทดสอบ)

### ลำดับขั้นการดำเนินงาน

1\. กำหนดโจทย์ ระบุอินพุตและเอาต์พุต และตั้งชื่ออุปกรณ์ X/Y/M

2\. เขียนเงื่อนไขการทำงานเป็นนิพจน์บูลีนและตารางความจริง/ลำดับเหตุการณ์

3\. เขียน Ladder และรายการคำสั่ง ตรวจกฎการเขียนและ Double coil

4\. จำลองใน GX Simulator3 แคปภาพผลทดสอบทุกสถานการณ์สำคัญ

5\. จัดทำรายงานและส่งตามกำหนด พร้อมอ้างอิงแหล่งข้อมูล
