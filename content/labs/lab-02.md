### 1. จุดประสงค์การทดลอง/การปฏิบัติงาน

1\. แปลงฟังก์ชันตรรกะ AND, OR, XOR และ 2 ใน 3 เป็นโปรแกรม Ladder ใน GX
Works3 ได้

2\. ทดสอบโปรแกรมด้วย GX Simulator3 และ/หรือ PLC FX5U จริง
และบันทึกผลเทียบกับตารางความจริงได้

3\. ต่ออินพุตแบบ Sink (สวิตช์ NO) และเอาต์พุตทรานซิสเตอร์ (หลอดไฟ 24 VDC)
ได้อย่างถูกต้องและปลอดภัย

4\. วิเคราะห์ความสอดคล้องระหว่างตารางความจริง นิพจน์บูลีน และ Ladder ได้

### 5. ขั้นตอนการตั้งค่าและทดสอบด้วย GX Works3 / GX Simulator3

1\. เปิด GX Works3 เลือก Project → New เลือก Series: FX5CPU, Type: FX5U,
Program Language: Ladder แล้วกด OK

2\. เปิด Program → MAIN → Program Body วางหน้าสัมผัสและคอยล์ตามภาพที่ 2.L2
ทีละแถว (4 แถว) แล้วใส่ END

3\. แปลงโปรแกรม (Convert, ปุ่ม F4) ตรวจว่าไม่มีข้อผิดพลาด

4\. เริ่มการจำลอง (Debug → Simulation → Start Simulation)
เขียนโปรแกรมลงตัวจำลองและตั้ง CPU เป็น RUN (ชื่อเมนูอาจต่างตามเวอร์ชัน)

5\. ลงทะเบียน X0, X1, X2, Y0–Y3 ใน Watch window แล้วเปลี่ยนค่า X0–X2 ครบ 8 ชุด
(000–111) พร้อมบันทึกค่า Y0–Y3 ลงตารางที่ 2.L2

6\. หากมีชุดฝึกจริง: ต่อสายตามภาพที่ 2.L1 ตั้งค่า Connection Destination, Online →
Write to PLC, ตั้ง CPU เป็น RUN และทดสอบด้วยสวิตช์จริง (หลังผู้สอนตรวจวงจร)

### คำถามท้ายการทดลอง/การปฏิบัติ

1\. ผลที่วัดได้ตรงกับตารางความจริงทุกแถวหรือไม่ หากไม่ตรงให้ระบุแถวและสาเหตุ

2\. จงเขียนสมการและโปรแกรมของเกต NOR (Y4 = (X0 + X1)̅) โดยใช้ NC อนุกรม
และพิสูจน์ด้วยเดอมอร์แกน

3\. ถ้าเปลี่ยนสวิตช์ SW0 เป็นแบบ NC (ต่อจริง) ที่ต่อกับ X0 ค่าตรรกะที่ PLC
อ่านได้เป็นอย่างไรเมื่อไม่กดสวิตช์ และต้องแก้โปรแกรมอย่างไรให้ได้ผลเท่าเดิม

4\. ต้องการให้ Y0 และ Y1 ห้ามติดพร้อมกัน (Interlock) ต้องเพิ่มหน้าสัมผัสใดในโปรแกรม

### ใบมอบงานหน่วยเรียนที่ 2

### จุดประสงค์เชิงพฤติกรรม

\- วิเคราะห์ระบบควบคุมแบบเปิด/ปิดจริง 1 ระบบ เขียนตารางความจริงและนิพจน์บูลีนได้

\- แปลงนิพจน์บูลีนเป็นแผนภาพ Ladder พร้อมรายการคำสั่งและตรวจสอบด้วยการจำลองได้

### หัวข้อการปฏิบัติงาน

"การออกแบบตรรกะควบคุมระบบอัตโนมัติขนาดเล็ก" — เลือกระบบ 1 ระบบ (เช่น
ไฟบันไดสองทาง ประตูอัตโนมัติที่เปิดเมื่อมีผู้ใช้บัตรและเซ็นเซอร์ตรวจจับ ระบบเตือนภัย 2 ใน 3
ปั๊มน้ำอัตโนมัติ) กำหนดอินพุต 3–4 ตัว เอาต์พุต 1–2 ตัว จัดทำรายงาน 2–3 หน้า

### สื่อการเรียน เครื่องมือ อุปกรณ์

\- ใบความรู้หน่วยที่ 2 และคู่มือ FX5U

\- คอมพิวเตอร์ที่ติดตั้ง GX Works3 (ใช้ GX Simulator3 ทดสอบ)

### ลำดับขั้นการดำเนินงาน

1\. กำหนดโจทย์ ระบุอินพุตและเอาต์พุต และตั้งชื่ออุปกรณ์ X/Y

2\. เขียนตารางความจริงและนิพจน์บูลีน

3\. ลดรูปด้วยกฎบูลีนหรือ K-map ระบุขั้นตอนการลดรูป

4\. เขียน Ladder และรายการคำสั่ง จำลองใน GX Simulator3
แคปภาพผลทดสอบทุกชุดอินพุต

5\. จัดทำรายงานและส่งตามกำหนด พร้อมอ้างอิงแหล่งข้อมูล
