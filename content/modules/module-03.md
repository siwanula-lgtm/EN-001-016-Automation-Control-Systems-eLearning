## จุดประสงค์การสอน

- **3.1 เข้าใจภาษา Ladder อุปกรณ์ และลำดับการประมวลผลของ PLC**
- **3.2 ใช้คำสั่งพื้นฐานของ PLC เขียนโปรแกรมควบคุมได้ถูกต้อง**
- **3.3 เข้าใจและออกแบบวงจร Self-holding, Interlock และ Toggle ได้**
- **3.4 เขียน ทดสอบ และตรวจสอบโปรแกรมด้วย GX Works3 / GX Simulator3 ได้**
- **จุดประสงค์เชิงพฤติกรรม เมื่อเรียนจบหน่วยนี้แล้ว ผู้เรียนสามารถ**
- **1) อธิบายหลักการประมวลผลตามรอบสแกนและระบุชนิดอุปกรณ์ X, Y, M, L, SM ได้ (LLO3)**
- **2) เขียนรายการคำสั่งและ Ladder ของนิพจน์ที่ใช้ LD, LDI, AND, ANI, OR, ORI, OUT ได้ (LLO3)**
- **3) ใช้ ANB, ORB, INV และ MPS/MRD/MPP กับนิพจน์ที่มีบล็อกและสาขาได้ (LLO3)**
- **4) ใช้ SET, RST, ZRST ควบคุมสถานะเอาต์พุตและอธิบายผลตามลำดับการสแกนได้ (LLO3)**
- **5) ใช้ PLS, PLF สร้างพัลส์ 1 รอบสแกนและออกแบบวงจร Toggle ได้ (LLO3)**
- **6) ออกแบบ Self-holding แบบ Stop priority/Start priority และ Interlock เดินหน้า–ถอยหลังได้ (LLO3)**
- **7) ตรวจพบและแก้ไข Double coil และเขียน ทดสอบโปรแกรมด้วย GX Simulator3 พร้อมบันทึกผลได้ (LLO3)**

## 3.1 ภาษา Ladder อุปกรณ์ และการประมวลผลโปรแกรม

ภาษา Ladder Diagram (LD) เป็นภาษาโปรแกรม PLC ตามมาตรฐาน IEC 61131-3
ที่พัฒนามาจากวงจรควบคุมรีเลย์ โปรแกรมประกอบด้วยรางไฟซ้ายและขวา
หน้าสัมผัสเป็นเงื่อนไขทางซ้าย และคอยล์หรือคำสั่งประยุกต์เป็นผลลัพธ์ทางขวา แต่ละแถวเรียกว่า
Rung ในหน่วยนี้ใช้ MELSEC iQ-F FX5U ซึ่งเขียนด้วย GX Works3
โดยอุปกรณ์ที่ใช้เก็บสถานะแบ่งตามชนิดดังภาพที่ 3.1

![ภาพที่ 3.1 ชนิดอุปกรณ์หลักของ MELSEC iQ-F FX5U (ค่าเริ่มต้นของพารามิเตอร์)](/images/book/a16_image38.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Mitsubishi Electric Corporation (n.d.))

**อุปกรณ์ X และ Y** เป็นเลขฐานแปดตามที่เรียนในหน่วยที่ 2 ส่วน M (Internal relay)
ใช้เก็บผลกลางทางหรือแฟล็กที่ไม่ต่อออกภายนอก L (Latch relay) คงค่าเมื่อไฟดับ และ SM
เป็นรีเลย์พิเศษของระบบ เช่น SM400 เป็น ON ตลอดเวลาที่ CPU อยู่ในสถานะ RUN และ
SM402 เป็น ON เพียงรอบสแกนแรกหลังเริ่ม RUN ใช้ตั้งค่าเริ่มต้นโปรแกรม

PLC ประมวลผลโปรแกรมเป็นรอบ ๆ ที่เรียกว่ารอบสแกน (Scan cycle) ดังภาพที่ 3.2
เริ่มจากอ่านอินพุตมาเก็บในหน่วยความจำภาพ (Input refresh)
จากนั้นประมวลผลโปรแกรมตั้งแต่แถวแรกถึงคำสั่ง END ตามลำดับบนลงล่างและซ้ายไปขวา
แล้วส่งผลไปยังเอาต์พุตจริง (Output refresh) ก่อนเริ่มรอบถัดไป

![ภาพที่ 3.2 ลำดับการประมวลผลของ PLC ในหนึ่งรอบสแกน](/images/book/a16_image39.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Mitsubishi Electric Corporation (n.d.))

กฎการเขียน Ladder ที่ต้องจำ ได้แก่ (1)
ทุกแถวต้องเริ่มจากรางไฟซ้ายและสิ้นสุดที่คอยล์หรือคำสั่งประยุกต์ (2)
ห้ามวางหน้าสัมผัสทางขวาของคอยล์ (3) หน้าสัมผัสของอุปกรณ์เดียวกันใช้ซ้ำได้ไม่จำกัดจำนวน
แต่คอยล์ของอุปกรณ์เดียวกันควรมีเพียงตัวเดียว (4) โปรแกรมต้องปิดท้ายด้วย END

**ตัวอย่างที่ 3.1** โปรแกรมมีแถว LD X0 / OUT M0 อยู่ก่อน แล้วตามด้วยแถว LD M0 /
OUT Y0 ถ้ากด X0 เมื่อถึงแถวที่สองรอบสแกนเดียวกัน M0 ถูกอัปเดตแล้ว Y0 จึงเป็น ON
ในรอบสแกนนั้น แต่ถ้าสลับลำดับสองแถว Y0 จะตามหลัง M0 ไปหนึ่งรอบสแกน
แสดงว่าลำดับแถวมีผลต่อเวลาตอบสนอง

## 3.2 คำสั่ง LD, LDI, AND, ANI, OR, ORI และ OUT

คำสั่งพื้นฐานทั้งเจ็ดแปลงตรรกะจากหน่วยที่ 2 เป็นโปรแกรมโดยตรง LD และ LDI
เริ่มแถวด้วยหน้าสัมผัส NO และ NC ตามลำดับ AND และ ANI ต่ออนุกรม OR และ ORI ต่อขนาน
ส่วน OUT ขับผลของเงื่อนไขไปยังคอยล์ ดังสรุปในตารางที่ 3.2

### ตารางที่ 3.2 คำสั่งหน้าสัมผัสและเอาต์พุตพื้นฐาน

| **คำสั่ง** | **ความหมาย**        | **ลักษณะใน Ladder**   | **ตัวอย่าง** |
|----------|---------------------|----------------------|------------|
| LD       | เริ่มแถวด้วยหน้าสัมผัส NO | หน้าสัมผัส NO ที่รางไฟซ้าย | LD X0      |
| LDI      | เริ่มแถวด้วยหน้าสัมผัส NC | หน้าสัมผัส NC ที่รางไฟซ้าย | LDI X1     |
| AND      | AND กับหน้าสัมผัส NO    | ต่ออนุกรม              | AND X1     |
| ANI      | AND กับหน้าสัมผัส NC    | ต่ออนุกรม (กลับค่า)      | ANI X2     |
| OR       | OR กับหน้าสัมผัส NO     | ต่อขนาน               | OR Y0      |
| ORI      | OR กับหน้าสัมผัส NC     | ต่อขนาน (กลับค่า)       | ORI X3     |
| OUT      | ขับเอาต์พุต/คอยล์       | คอยล์ท้ายแถว           | OUT Y0     |

![ภาพที่ 3.3 ตัวอย่างวงจร AND, OR, NOT และรายการคำสั่ง](/images/book/a16_image40.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Mitsubishi Electric Corporation (n.d.))

**ตัวอย่างที่ 3.2** เขียนรายการคำสั่งของ Y0 = (X0 + X1)·X̅2 โดย X0 และ X1
ต่อขนานกัน แล้วอนุกรมกับ NC ของ X2 ได้ LD X0 / OR X1 / ANI X2 / OUT Y0
ตรวจด้วยตารางความจริง: Y0 เป็น 1 เมื่อ X0 หรือ X1 เป็น 1 และ X2 เป็น 0 เท่านั้น

หมายเหตุ: หน้าสัมผัสของสวิตช์ภายนอกที่ต่อแบบ NC จริงจะให้ค่า 1 ที่อินพุตเมื่อไม่ได้กดสวิตช์
โปรแกรมที่ใช้ปุ่ม STOP แบบ NC จึงต้องใช้ AND (หน้าสัมผัส NO) ไม่ใช่ ANI การเลือกใช้ ANI
หรือ AND ต้องดูชนิดสวิตช์ที่ต่อจริงเสมอ

## 3.3 คำสั่งรวมบล็อกและแยกสาขา: ANB, ORB, INV, MPS/MRD/MPP

เมื่อนิพจน์มีกลุ่มของหน้าสัมผัสมากกว่าหนึ่งกลุ่ม ต้องใช้คำสั่งรวมบล็อก ORB รวมสองบล็อกด้วย OR
เช่น (X0·X1) + (X2·X3) และ ANB รวมสองบล็อกด้วย AND เช่น (X0 + X1)·(X2 + X3)
ทั้งสองคำสั่งไม่มีตัวถูกดำเนินการและต้องมีจำนวนไม่เกินจำนวน LD/LDI ที่ใช้เริ่มบล็อก

![ภาพที่ 3.4 การใช้ ORB และ ANB กับบล็อกวงจร](/images/book/a16_image41.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Mitsubishi Electric Corporation (n.d.))

คำสั่ง INV กลับค่าผลการคำนวณก่อนหน้าทั้งหมด เช่น LD X0 / AND X1 / INV / OUT Y0 ให้
NAND ของ X0 และ X1 ส่วน MPS, MRD, MPP
ใช้เมื่อมีเงื่อนไขร่วมหนึ่งชุดแตกไปขับหลายเอาต์พุต MPS เก็บผลการคำนวณ ณ จุดแยก MRD
อ่านค่าที่เก็บ และ MPP อ่านค่าพร้อมคืนค่าที่เก็บ

![ภาพที่ 3.5 การแยกสาขาด้วย MPS / MRD / MPP](/images/book/a16_image42.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Mitsubishi Electric Corporation (n.d.))

### ตารางที่ 3.3 คำสั่งรวมบล็อก กลับค่า และแยกสาขา

| **คำสั่ง** | **ความหมาย**          | **ใช้เมื่อ**                    |
|----------|-----------------------|------------------------------|
| ANB      | AND ระหว่างบล็อก        | ผลคูณของกลุ่มที่เป็นผลรวม          |
| ORB      | OR ระหว่างบล็อก         | ผลรวมของกลุ่มที่เป็นผลคูณ          |
| INV      | กลับค่าผลลัพธ์ก่อนหน้า      | ต้องการ NAND/NOR หรือกลับทั้งนิพจน์ |
| MPS      | เก็บผลการคำนวณ ณ จุดแยก | เริ่มแยกสาขาเอาต์พุต             |
| MRD      | อ่านค่าที่เก็บ             | สาขากลางที่ยังมีสาขาถัดไป         |
| MPP      | อ่านค่าที่เก็บแล้วคืนค่า      | สาขาสุดท้ายของจุดแยก            |

**ตัวอย่างที่ 3.3** ต้องการให้ X0 เป็นเงื่อนไขร่วมของเอาต์พุตสามตัว คือ Y0 = X0·X1, Y1
= X0·X2 และ Y2 = X0·X3 เขียนได้ LD X0 / MPS / AND X1 / OUT Y0 / MRD / AND
X2 / OUT Y1 / MPP / AND X3 / OUT Y2 ทำให้ไม่ต้องอ่าน X0 ซ้ำและโปรแกรมอ่านง่ายขึ้น

## 3.4 คำสั่ง SET, RST และ ZRST

คำสั่ง SET ทำให้อุปกรณ์เป็น ON และคงสถานะแม้เงื่อนไขหายไปแล้ว จนกว่าจะถูกล้างด้วย RST
จึงใช้แทนวงจร Self-holding เมื่อต้องการเขียนเงื่อนไขเริ่มและเงื่อนไขหยุดแยกกัน ส่วน
ZRST (Zone Reset) ล้างอุปกรณ์ชนิดเดียวกันทั้งช่วงในคำสั่งเดียว เช่น ZRST Y0 Y7
ล้างเอาต์พุต Y0 ถึง Y7

คำสั่งที่อยู่ท้ายสุดในโปรแกรมจะชนะ ผู้ออกแบบจึงต้องวางแถว RST (หยุด) ไว้หลังแถว SET

(ปุ่มหยุดฉุกเฉินเชิงโปรแกรม) เขียนได้ LD X2 / ZRST Y0 Y7
ถ้าวางแถวนี้ไว้ท้ายโปรแกรมก่อน END ผลของ ZRST จะทับค่าที่แถวก่อนหน้าเขียนไว้ใน OUT ของ
Y0–Y7 ในรอบสแกนเดียวกัน

## 3.5 คำสั่งตรวจจับขอบสัญญาณ PLS และ PLF

PLS (Pulse) ทำให้อุปกรณ์ที่ระบุเป็น ON เพียง 1 รอบสแกนเมื่อเงื่อนไขเปลี่ยนจาก OFF เป็น
ON (ขอบขาขึ้น) ส่วน PLF (Pulse Falling) ทำเช่นเดียวกันที่ขอบขาลง
คำสั่งนี้ใช้เมื่อต้องการให้การกดปุ่มหนึ่งครั้งเกิดผลเพียงครั้งเดียว ไม่ว่าจะกดค้างนานเท่าใด
นอกจากนี้ FX5U ยังมีหน้าสัมผัสแบบขอบ เช่น LDP/LDF/ANDP/ANDF/ORP/ORF ที่ให้ผลคล้ายกัน

## 3.6 Self-holding, Interlock, Toggle และ Double coil

**Self-holding** คือการนำหน้าสัมผัสของเอาต์พุตมาต่อขนานกับปุ่ม START
เพื่อคงสถานะเอาต์พุตหลังปล่อยปุ่ม แบบ Stop priority ต่ออนุกรมกับ STOP ภายนอกกลุ่มขนาน
จึง STOP ชนะเมื่อกดพร้อมกัน แบบ Start priority ต่อ STOP ไว้ในสาขาของตัวเองเท่านั้น
จึง START ชนะ โรงงานส่วนใหญ่เลือก Stop priority เพื่อความปลอดภัย

### ตารางที่ 3.4 เปรียบเทียบ Self-holding กับ SET/RST

| **หัวข้อ**             | **Self-holding**           | **SET / RST**                |
|----------------------|----------------------------|------------------------------|
| จำนวนแถว             | 1 แถว (OUT เพียงตัวเดียว)     | 2 แถว (เริ่ม และ หยุด แยกกัน)    |
| ลำดับความสำคัญ         | กำหนดจากตำแหน่ง STOP ในวงจร | กำหนดจากลำดับแถว (แถวท้ายชนะ)  |
| สถานะเมื่อ PLC หยุด RUN | ดับ (เอาต์พุตปกติถูกล้าง)        | ดับ เว้นแต่ใช้อุปกรณ์แบบ Latch (L) |
| เหมาะกับ              | มอเตอร์ Start/Stop ทั่วไป     | ธงสถานะ ลำดับงานหลายเงื่อนไข    |

**Interlock** คือการนำหน้าสัมผัส NC ของเอาต์พุตฝั่งตรงข้ามมาต่ออนุกรม
เพื่อป้องกันเอาต์พุตสองตัวทำงานพร้อมกัน เช่น คอนแทกเตอร์เดินหน้าและถอยหลังของมอเตอร์ 3
เฟส หากทำงานพร้อมกันจะเกิดไฟลัดวงจรระหว่างเฟส นอกจาก Interlock ในโปรแกรมแล้ว
ระบบจริงควรมี Interlock เชิงกลหรือหน้าสัมผัสช่วยของคอนแทกเตอร์ต่อในวงจรไฟฟ้าด้วย

![ภาพที่ 3.13 วงจร Interlock สำหรับเดินหน้า (Y0) และถอยหลัง (Y1)](/images/book/a16_image50.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Mitsubishi Electric Corporation (n.d.))

**วงจรสลับสถานะ (Toggle)** ใช้ปุ่มเดียวสลับเอาต์พุต ON/OFF ทุกครั้งที่กด ต้องใช้ PLS
สร้างพัลส์ 1 สแกนก่อน แล้วใช้สมการ Y0 = M0 ⊕ Y0 ภายในแถวเดียว เพราะแถวเดียวอ่านค่า
Y0 เดิมก่อนเขียนค่าใหม่ หากแยกเป็นแถว SET แล้วแถว RST ภายใต้พัลส์เดียวกัน
เอาต์พุตจะถูกสลับสองครั้งในรอบสแกนเดียวและไม่เปลี่ยนค่า

![ภาพที่ 3.14 วงจร Toggle ด้วย PLS และสมการ XOR](/images/book/a16_image51.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Mitsubishi Electric Corporation (n.d.))

**Double coil** คือการเขียน OUT ให้อุปกรณ์เดียวกันมากกว่าหนึ่งแถว
ผลคือแถวท้ายสุดเป็นตัวกำหนดค่า ส่วนแถวก่อนหน้าไม่มีผลต่อเอาต์พุตจริง แม้ GX Works3
จะยอมให้คอมไพล์ได้ แต่เป็นข้อผิดพลาดที่พบบ่อยและค้นหายาก แก้ไขได้ด้วยการรวมเงื่อนไขด้วย
OR ในแถวเดียว

![ภาพที่ 3.15 ปัญหา Double coil ที่ต้องหลีกเลี่ยง](/images/book/a16_image52.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Mitsubishi Electric Corporation (n.d.))

### สรุปท้ายใบความรู้

\- PLC ประมวลผลบนลงล่าง ซ้ายไปขวาเป็นรอบสแกน ค่าอุปกรณ์ที่เขียนท้ายสุดมีผล
และทุกโปรแกรมต้องปิดด้วย END

\- LD/LDI เริ่มแถว AND/ANI ต่ออนุกรม OR/ORI ต่อขนาน OUT ขับคอยล์ ORB/ANB
รวมบล็อก INV กลับค่า MPS/MRD/MPP แยกสาขา

\- SET คงสถานะ RST ล้างสถานะ ZRST ล้างเป็นช่วง; PLS/PLF ให้พัลส์ 1
รอบสแกนที่ขอบขาขึ้น/ขาลง

\- Stop priority ปลอดภัยกว่า Start priority; Interlock
ป้องกันเอาต์พุตตรงข้ามทำงานพร้อมกัน

\- Toggle ต้องใช้พัลส์ 1 สแกนและสมการ XOR ในแถวเดียว; หลีกเลี่ยง Double coil
เสมอ

## บทสรุป

คำสั่งพื้นฐานของ PLC คือชุดคำสั่งที่ใช้แปลงตรรกะควบคุมเป็นโปรแกรม Ladder
และรายการคำสั่ง (Instruction List) ได้แก่ LD, LDI, AND, ANI, OR, ORI, OUT
สำหรับเงื่อนไขและเอาต์พุต ANB, ORB, INV และ MPS/MRD/MPP สำหรับจัดการบล็อกและสาขา
SET, RST, ZRST สำหรับเก็บและล้างสถานะ และ PLS, PLF สำหรับตรวจจับขอบสัญญาณ PLC
ประมวลผลโปรแกรมจากบนลงล่างและซ้ายไปขวาเป็นรอบสแกน
อุปกรณ์ที่ถูกเขียนค่าท้ายสุดในรอบสแกนจะเป็นค่าที่มีผล
ผู้ปฏิบัติงานจึงต้องเข้าใจลำดับแถวเพื่อออกแบบวงจร Self-holding, Interlock และ
Toggle ให้ทำงานถูกต้องและปลอดภัย

## แบบฝึกหัดท้ายหน่วยเรียน

คำชี้แจง: ให้นักศึกษาตอบคำถามต่อไปนี้ให้ถูกต้อง (10 ข้อ)

**1. เขียนรายการคำสั่งของ Y0 = (X0 + X1) · X̅2 · X3 (X0, X1 ต่อขนานกัน)**

<details><summary>เฉลย</summary>

Given/Determine: นิพจน์ Y0 = (X0 + X1)·X̅2·X3 ; หารายการคำสั่ง

Assumption/ระบบ: X0–X3 เป็นสวิตช์ NO; อนุกรม = AND, ขนาน = OR, NC = ANI

สมการ: Y0 = (X0 + X1)·X̅2·X3

วิธีทำ: เริ่มด้วย LD X0 แล้ว OR X1 ได้ (X0 + X1) ต่อด้วย ANI X2 และ AND X3 แล้ว OUT Y0

ผลเฉลย: LD X0 / OR X1 / ANI X2 / AND X3 / OUT Y0 / END

</details>

**2. จากรายการคำสั่ง LD X0 / AND X1 / LD X2 / AND X3 / ORB / OUT Y0 จงเขียนนิพจน์บูลีนของ Y0**

<details><summary>เฉลย</summary>

Given/Determine: IL ที่กำหนด ; หา Y0

Assumption/ระบบ: LD...AND สองชุดเป็นสองบล็อก; ORB = OR ระหว่างบล็อก

สมการ: Y0 = (X0·X1) + (X2·X3)

วิธีทำ: บล็อกแรก LD X0 AND X1 = X0·X1 บล็อกที่สอง LD X2 AND X3 = X2·X3 จากนั้น ORB รวมสองบล็อกด้วย OR

ผลเฉลย: Y0 = X0·X1 + X2·X3

</details>

**3. จงเขียนรายการคำสั่งและอธิบาย Ladder ของ Y1 = (X0 + X1)·(X2 + X3)**

<details><summary>เฉลย</summary>

Given/Determine: Y1 = (X0 + X1)·(X2 + X3) ; หา IL

Assumption/ระบบ: เป็นผลคูณของผลรวมสองกลุ่ม ต้องใช้ ANB

สมการ: Y1 = (X0 + X1)·(X2 + X3)

วิธีทำ: บล็อกแรก LD X0 OR X1 บล็อกที่สอง LD X2 OR X3 แล้ว ANB รวมสองบล็อกด้วย AND ใน Ladder คือสองกลุ่มขนานต่ออนุกรมกัน

ผลเฉลย: LD X0 / OR X1 / LD X2 / OR X3 / ANB / OUT Y1 / END

</details>

**4. จงเขียนโปรแกรมของเกต NAND สองอินพุต Y0 = (X0·X1)̅ โดยใช้ INV และโดยใช้เดอมอร์แกน (หน้าสัมผัส NC)**

<details><summary>เฉลย</summary>

Given/Determine: Y0 = (X0·X1)̅ ; เขียน IL สองแบบ

Assumption/ระบบ: ใช้เดอมอร์แกน (A·B)̅ = A̅ + B̅

สมการ: Y0 = X̅0 + X̅1

วิธีทำ: แบบ INV: LD X0 / AND X1 / INV / OUT Y0 แบบเดอมอร์แกน: NC ของ X0 ขนานกับ NC ของ X1 ได้ LDI X0 / ORI X1 / OUT Y0

ผลเฉลย: ทั้งสองแบบให้ผลเท่ากัน: Y0 = 0 เฉพาะเมื่อ X0 = X1 = 1

</details>

**5. มอเตอร์ใช้ START (X0, NO), STOP (X1, ต่อแบบ NC), โอเวอร์โหลด (X2, ต่อแบบ NC) ออกแบบ Self-holding ขับ Y0 แบบ Stop priority**

<details><summary>เฉลย</summary>

Given/Determine: X0 = START (NO), X1 = STOP (NC จริง), X2 = โอเวอร์โหลด (NC จริง) ; ออกแบบ Y0

Assumption/ระบบ: สวิตช์ NC จริงให้ค่า 1 เมื่อไม่ได้กด/ปกติ จึงใช้ AND (หน้าสัมผัส NO) ในโปรแกรม

สมการ: Y0 = (X0 + Y0)·X1·X2

วิธีทำ: START ขนานกับ Y0 แล้วอนุกรมกับ X1 และ X2 ในรูป NO เมื่อกด STOP หรือโอเวอร์โหลด X1/X2 เป็น 0 Y0 ดับและไม่คงสถานะ

ผลเฉลย: LD X0 / OR Y0 / AND X1 / AND X2 / OUT Y0 / END (วงจรปลอดภัยเมื่อสายขาดเพราะค่าอินพุตเป็น 0)

</details>

**6. โปรแกรมมีแถว LD X0 / SET Y1 และแถว LD X1 / RST Y1 (แถว RST อยู่หลัง) จงบอกค่า Y1 เมื่อ (X0,X1) = (1,0), (0,0), (0,1), (1,1) ตามลำดับ โดย Y1 เริ่มต้นเป็น 0**

<details><summary>เฉลย</summary>

Given/Determine: ลำดับอินพุต (1,0) → (0,0) → (0,1) → (1,1) ; หา Y1 แต่ละขั้น

Assumption/ระบบ: SET คงสถานะ RST ล้างสถานะ และแถวท้ายสุดชนะเมื่อสั่งพร้อมกัน

สมการ: Y1 ใหม่ = RST ? 0 : (SET ? 1 : Y1 เดิม)

วิธีทำ: (1,0): SET ทำงาน Y1 = 1; (0,0): ไม่มีคำสั่งใดทำงาน Y1 คงเดิม = 1; (0,1): RST ทำงาน Y1 = 0; (1,1): SET ทำงานก่อนแล้ว RST ทับ Y1 = 0

ผลเฉลย: Y1 = 1, 1, 0, 0 ตามลำดับ

</details>

**7. จงเขียนโปรแกรมให้เมื่อกด X7 ล้างเอาต์พุต Y0–Y7 และรีเลย์ภายใน M0–M7 ทั้งหมด**

<details><summary>เฉลย</summary>

Given/Determine: ล้าง Y0–Y7 และ M0–M7 เมื่อ X7 = ON

Assumption/ระบบ: ZRST ล้างอุปกรณ์ชนิดเดียวกันต่อหนึ่งคำสั่ง จึงต้องใช้สองคำสั่ง

สมการ: X7 = 1 → Y0..Y7 = 0 และ M0..M7 = 0

วิธีทำ: ใช้เงื่อนไข LD X7 แล้ว ZRST Y0 Y7 จากนั้นใช้ LD X7 อีกครั้งแล้ว ZRST M0 M7 (หรือใช้ MPS/MPP ร่วมกัน) วางไว้ท้ายโปรแกรม

ผลเฉลย: LD X7 / ZRST Y0 Y7 / LD X7 / ZRST M0 M7 / END

</details>

**8. ออกแบบวงจรเลือกทางเดียวจากสามทาง: X0, X1, X2 เป็นปุ่มเลือก Y0, Y1, Y2 ตามลำดับ X3 เป็น STOP ทุกทางต้อง Interlock กัน จงเขียนรายการคำสั่งของ Y0**

<details><summary>เฉลย</summary>

Given/Determine: ปุ่มเลือก X0–X2, STOP X3 (NO) ; หา IL ของ Y0

Assumption/ระบบ: Y0 ต้องไม่ทำงานเมื่อ Y1 หรือ Y2 เป็น ON; ใช้ Stop priority

สมการ: Y0 = (X0 + Y0)·X̅3·Y̅1·Y̅2

วิธีทำ: Self-holding ของ Y0 ต่ออนุกรมกับ NC ของ X3, Y1 และ Y2 ส่วน Y1 และ Y2 เขียนในลักษณะเดียวกันโดยสลับเอาต์พุตตรงข้าม

ผลเฉลย: LD X0 / OR Y0 / ANI X3 / ANI Y1 / ANI Y2 / OUT Y0 (Y1: LD X1 OR Y1 ANI X3 ANI Y0 ANI Y2 OUT Y1; Y2: LD X2 OR Y2 ANI X3 ANI Y0 ANI Y1 OUT Y2)

</details>

**9. จงเขียนวงจร Toggle ที่ใช้ปุ่ม X0 สลับหลอดไฟ Y0 และอธิบายว่าเหตุใดต้องใช้ PLS**

<details><summary>เฉลย</summary>

Given/Determine: ปุ่ม X0 สลับ Y0 ; เหตุผลการใช้ PLS

Assumption/ระบบ: X0 เป็น ON ต่อเนื่องหลายรอบสแกนขณะกดปุ่ม

สมการ: M0 = พัลส์ 1 สแกนจาก X0 ; Y0 = M0 ⊕ Y0

วิธีทำ: แถวที่ 1: LD X0 / PLS M0 แถวที่ 2: LD M0 / ANI Y0 / LDI M0 / AND Y0 / ORB / OUT Y0 หากไม่มี PLS ขณะกดค้าง Y0 จะสลับค่าทุกรอบสแกน เพราะ M0 จะเป็น 1 ต่อเนื่อง

ผลเฉลย: LD X0 / PLS M0 / LD M0 / ANI Y0 / LDI M0 / AND Y0 / ORB / OUT Y0 / END

</details>

**10. โปรแกรม LD X0 / OUT Y0 / LD X1 / OUT Y0 / END มีปัญหาใด จงหาค่า Y0 เมื่อ (X0,X1) = (1,0), (0,1), (1,1), (0,0) และแก้ไขโปรแกรม**

<details><summary>เฉลย</summary>

Given/Determine: โปรแกรมมี OUT Y0 สองแถว ; หา Y0 ในสี่กรณีและแก้ไข

Assumption/ระบบ: ค่าที่เขียนท้ายสุดในรอบสแกนเป็นค่าที่มีผล

สมการ: Y0 = X1 (แถวท้ายทับแถวแรก)

วิธีทำ: (1,0): แถวแรกเขียน 1 แถวท้ายเขียน 0 ทับ Y0 = 0; (0,1): Y0 = 1; (1,1): Y0 = 1; (0,0): Y0 = 0 แสดงว่า X0 ไม่มีผล เพราะเป็น Double coil จึงรวมเงื่อนไขเป็น LD X0 / OR X1 / OUT Y0

ผลเฉลย: Y0 = 0, 1, 1, 0 ตามลำดับ; แก้เป็น LD X0 / OR X1 / OUT Y0 / END

</details>
