## 2.1 ระบบเลขและการแปลงเลขฐาน

วงจรดิจิทัลและ PLC ประมวลผลสัญญาณที่มีเพียงสองสถานะ คือ 0 (OFF, แรงดันต่ำ) และ 1
(ON, แรงดันสูง) ข้อมูลหนึ่งหลักเรียกว่า **บิต (bit)** ข้อมูล 8 บิตเรียกว่า **ไบต์
(byte)** และรีจิสเตอร์ข้อมูล (D) ของ PLC ตระกูล FX5 มีขนาด 16 บิต (Mitsubishi
Electric Corporation, n.d.) ระบบเลขที่พบบ่อยในงาน PLC มี 4 ฐาน ได้แก่ ฐานสอง
(Binary, 0–1) ฐานแปด (Octal, 0–7) ฐานสิบ (Decimal, 0–9) และฐานสิบหก
(Hexadecimal, 0–9 และ A–F)

ค่าของเลขฐาน r ใด ๆ คำนวณจากผลรวมของ (ค่าหลัก × r^ตำแหน่ง) เช่น 1101₂ =
1×2³ + 1×2² + 0×2¹ + 1×2⁰ = 13 การแปลงฐานสิบเป็นฐานสองทำโดยหารด้วย 2
ซ้ำและอ่านเศษจากล่างขึ้นบน หรือลบด้วยค่าน้ำหนักบิต (128, 64, 32, …)
ส่วนการแปลงระหว่างฐานสอง ฐานแปด และฐานสิบหกทำได้โดยจัดกลุ่มบิตทีละ 3 บิต (ฐานแปด)
หรือ 4 บิต (ฐานสิบหก) ดังภาพที่ 2.1

ที่มีอินพุต 16 จุดจะมี X0–X7 และ X10–X17

## 2.2 ลอจิกเกตและตารางความจริง

ลอจิกเกต (Logic gate) คือวงจรที่รับอินพุตแบบ 0/1 แล้วให้เอาต์พุตตามฟังก์ชันตรรกะ
ฟังก์ชันพื้นฐานมี 3 ชนิด คือ AND, OR และ NOT และประกอบเป็น NAND, NOR, XOR และ
XNOR ได้ ตารางความจริง (Truth table) คือตารางที่แสดงเอาต์พุตของทุกชุดค่าอินพุต
โดยฟังก์ชันที่มี n อินพุตจะมี 2ⁿ แถว (Floyd, 2015)
สัญลักษณ์และตารางความจริงของเกตแต่ละชนิดแสดงในภาพที่ 2.2

![ภาพที่ 2.2 สัญลักษณ์และตารางความจริงของลอจิกเกตพื้นฐาน (AND, OR, NOT, NAND, NOR, XOR)](/images/book/a16_image25.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Floyd (2015) และมาตรฐาน IEEE/ANSI Std 91)

### ตารางที่ 2.3 ฟังก์ชันตรรกะและนิพจน์บูลีนของเกตพื้นฐาน

| **เกต** | **นิพจน์บูลีน** | **เงื่อนไขที่เอาต์พุต = 1** | **ตรรกะใน Ladder**     |
|---------|-------------|-----------------------|------------------------|
| AND     | Y = A · B   | อินพุตทุกตัวเป็น 1         | หน้าสัมผัสต่ออนุกรม         |
| OR      | Y = A + B   | อย่างน้อยหนึ่งอินพุตเป็น 1   | หน้าสัมผัสต่อขนาน          |
| NOT     | Y = A̅       | อินพุตเป็น 0             | หน้าสัมผัส NC             |
| NAND    | Y = (A · B)̅ | ไม่ใช่กรณีที่อินพุตทุกตัวเป็น 1 | NC ขนานกัน (เดอมอร์แกน)  |
| NOR     | Y = (A + B)̅ | อินพุตทุกตัวเป็น 0         | NC อนุกรมกัน (เดอมอร์แกน) |
| XOR     | Y = A ⊕ B   | อินพุตทั้งสองมีค่าต่างกัน     | NO กับ NC ไขว้ขนานกัน     |
| XNOR    | Y = (A ⊕ B)̅ | อินพุตทั้งสองมีค่าเท่ากัน     | NO·NO ขนานกับ NC·NC     |

## 2.3 พีชคณิตบูลีน ทฤษฎีบทของเดอมอร์แกน และการลดรูป

พีชคณิตบูลีน (Boolean algebra) คือระบบคณิตศาสตร์ที่ใช้ตัวแปรมีค่า 0 หรือ 1
และตัวดำเนินการ AND (·), OR (+) และ NOT (ขีดบน)
ใช้วิเคราะห์และลดรูปวงจรตรรกะให้ใช้หน้าสัมผัสหรือคำสั่งน้อยที่สุด กฎที่ใช้บ่อยสรุปในตารางที่
2.4

### ตารางที่ 2.4 กฎพื้นฐานของพีชคณิตบูลีน

| **กฎ**                   | **รูปแบบ AND**         | **รูปแบบ OR**              |
|--------------------------|-----------------------|---------------------------|
| เอกลักษณ์ (Identity)       | A · 1 = A             | A + 0 = A                 |
| ค่าว่าง/ค่าเต็ม (Null)       | A · 0 = 0             | A + 1 = 1                 |
| ซ้ำตัวเอง (Idempotent)     | A · A = A             | A + A = A                 |
| คอมพลีเมนต์ (Complement)   | A · A̅ = 0             | A + A̅ = 1                 |
| การสลับที่ (Commutative)    | A · B = B · A         | A + B = B + A             |
| การจัดหมู่ (Associative)    | (A·B)·C = A·(B·C)     | (A+B)+C = A+(B+C)         |
| การแจกแจง (Distributive) | A·(B + C) = A·B + A·C | A + B·C = (A + B)·(A + C) |
| การดูดกลืน (Absorption)    | A · (A + B) = A       | A + A·B = A               |
| เดอมอร์แกน (De Morgan)    | (A · B)̅ = A̅ + B̅       | (A + B)̅ = A̅ · B̅           |

**ทฤษฎีบทของเดอมอร์แกน** กล่าวว่า การกลับค่าผลรวมเท่ากับผลคูณของค่าที่ถูกกลับ
และการกลับค่าผลคูณเท่ากับผลรวมของค่าที่ถูกกลับ ในงาน PLC ใช้แปลงเงื่อนไข "ไม่ใช่ (A หรือ
B)" ให้เป็นหน้าสัมผัส NC สองตัวต่ออนุกรมกัน ดังภาพที่ 2.3

![ภาพที่ 2.3 ทฤษฎีบทของเดอมอร์แกนในรูปแบบ Ladder (NOR และ NAND)](/images/book/a16_image26.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Floyd (2015))

**ตัวอย่างที่ 2.3** ลดรูป Y = A·B + A·B̅ + A̅·B จัดรูป A·B + A·B̅ = A(B + B̅) = A
ดังนั้น Y = A + A̅·B ใช้กฎ A + A̅·B = A + B (จากการแจกแจง (A + A̅)(A + B) = A +
B) ได้ Y = A + B

**แผนที่คาร์โนห์ (Karnaugh map, K-map)** ใช้ลดรูปฟังก์ชัน 2–4
ตัวแปรด้วยการรวมกลุ่มช่อง "1" ที่อยู่ติดกันเป็นสี่เหลี่ยมขนาด 1, 2, 4 หรือ 8 ช่อง (กำลังของ
2) โดยแถวและคอลัมน์เรียงแบบรหัสเกรย์ (00, 01, 11, 10) กลุ่มที่ใหญ่ขึ้นตัดตัวแปรได้มากขึ้น
ภาพที่ 2.4 เป็นฟังก์ชันเสียงข้างมาก (Y = 1 เมื่ออินพุตเป็น 1 อย่างน้อย 2 ใน 3 ตัว) ได้ผลลดรูป Y = AB + AC + BC

![ภาพที่ 2.4 แผนที่คาร์โนห์ (Karnaugh map) 3 ตัวแปรของฟังก์ชันเสียงข้างมาก 2 ใน 3](/images/book/a16_image27.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Floyd (2015))

## 2.4 การแปลงตรรกะเป็นแผนภาพ Ladder

แผนภาพ Ladder (Ladder Diagram, LD) พัฒนามาจากวงจรควบคุมรีเลย์
มีรางไฟซ้ายและขวา หน้าสัมผัสอยู่ทางซ้ายเป็นเงื่อนไข และคอยล์เอาต์พุตอยู่ทางขวา (IEC,
2013) หลักการแปลงตรรกะเป็น Ladder มีดังนี้ (1) หน้าสัมผัส NO แทนตัวแปรที่เป็น 1
จึงจะนำกระแส (2) หน้าสัมผัส NC แทนตัวแปรกลับค่า (NOT) (3) การต่ออนุกรมแทน AND (4)
การต่อขนานแทน OR และ (5) คอยล์ OUT แทนเอาต์พุต ดังภาพที่ 2.5

![ภาพที่ 2.5 การแทนฟังก์ชัน AND, OR, NOT ด้วยหน้าสัมผัสและแผนภาพ Ladder](/images/book/a16_image28.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Mitsubishi Electric Corporation (n.d.) และ IEC

|-----------|-------------------------------|--------------------------|
| LD        | เริ่มต้นแถวด้วยหน้าสัมผัส NO         | หน้าสัมผัส NO ที่ต่อกับรางไฟซ้าย |

## 2.5 ตรรกะที่มีหน่วยความจำ: Self-holding, SET/RST และ Interlock

ลอจิกเกตพื้นฐานเป็น **วงจรเชิงการจัดหมู่ (Combinational)**
ที่เอาต์พุตขึ้นกับอินพุตปัจจุบันเท่านั้น แต่งานควบคุมจริงต้องการ "จดจำ" สถานะ เช่น กดปุ่ม
START ครั้งเดียวแล้วมอเตอร์ทำงานต่อ จึงใช้ **วงจรเชิงลำดับ (Sequential)**
ที่เอาต์พุตขึ้นกับอินพุตและสถานะก่อนหน้า วิธีที่ใช้ในงาน PLC มีสองแบบดังภาพที่ 2.9

![ภาพที่ 2.9 วงจรคงสถานะ (Self-holding) และการใช้คำสั่ง SET/RST เป็นแลตช์](/images/book/a16_image31.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Mitsubishi Electric Corporation (n.d.))

\- **Self-holding (วงจรคงสถานะ)** นำหน้าสัมผัส Y0 มาต่อขนานกับ START (X0)
และต่ออนุกรมกับ NC ของ STOP (X1) ได้ Y0 = (X0 + Y0)·X̅1 เมื่อ STOP และ START
กดพร้อมกัน Y0 ดับ จึงเป็นแบบให้ STOP มีลำดับความสำคัญสูงกว่า (Reset-dominant)

\- **SET/RST** คำสั่ง SET Y1 ทำให้ Y1 เป็น ON คงสถานะแม้อินพุตหายไป จนกว่าคำสั่ง
RST Y1 จะทำงาน เมื่อ SET และ RST ทำงานพร้อมกัน
คำสั่งที่เขียนไว้ท้ายกว่าในโปรแกรมจะมีผล เพราะ PLC ประมวลผลจากบนลงล่าง (Mitsubishi
Electric Corporation, n.d.)

**Interlock (อินเตอร์ล็อก)** คือการใช้หน้าสัมผัส NC
ของเอาต์พุตตัวหนึ่งต่ออนุกรมในวงจรของเอาต์พุตอีกตัวหนึ่ง เพื่อไม่ให้ทั้งสองทำงานพร้อมกัน เช่น
คอนแทกเตอร์เดินหน้า (Y0) และถอยหลัง (Y1) ของมอเตอร์สามเฟส
หากทำงานพร้อมกันจะเกิดการลัดวงจรระหว่างเฟส ภาพที่ 2.10 แสดงวงจรที่ Y0 และ Y1
ล็อกกันเอง โดยมี X2 เป็นปุ่ม STOP ร่วม
ในงานจริงควรมีอินเตอร์ล็อกทางกลหรือทางไฟฟ้าของคอนแทกเตอร์ซ้ำอีกชั้นหนึ่งด้วย

![ภาพที่ 2.10 วงจรอินเตอร์ล็อก (Interlock) ป้องกันเอาต์พุตทำงานพร้อมกัน](/images/book/a16_image32.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Mitsubishi Electric Corporation (n.d.))

## 2.6 อินพุต/เอาต์พุตดิจิทัลของ FX5U

อินพุตดิจิทัลรับสัญญาณ ON/OFF จากปุ่มกด สวิตช์ และเซ็นเซอร์ ส่วนเอาต์พุตขับหลอดไฟ รีเลย์
หรือคอนแทกเตอร์ FX5U แบบ ES มีอินพุตที่เลือกต่อแบบ Sink หรือ Source ได้ที่ขั้ว S/S
กล่าวคือ ต่อ S/S กับ +24 V ใช้กับเซ็นเซอร์ NPN (Sink) และต่อ S/S กับ 0 V
ใช้กับเซ็นเซอร์ PNP (Source) ดังภาพที่ 2.11 ส่วนเอาต์พุตแบบทรานซิสเตอร์ MT เป็นแบบ
Sink ซึ่งต้องต่อโหลดระหว่าง +24 V กับขั้ว Y และต่อขั้ว COM เข้ากับ 0 V (Mitsubishi
Electric Corporation, n.d.)

### สรุปท้ายใบความรู้

\- PLC ประมวลผลข้อมูลสองสถานะ จึงต้องเข้าใจเลขฐานสอง ฐานแปด และฐานสิบหก เลข
X/Y ของ FX5U เป็นฐานแปด

\- ลอจิกเกตทุกชนิดอธิบายด้วยตารางความจริงและนิพจน์บูลีน และลดรูปได้ด้วยกฎบูลีน
เดอมอร์แกน และ K-map

\- อนุกรม = AND, ขนาน = OR, NC = NOT ทำให้แปลงนิพจน์บูลีนเป็น Ladder ได้ตรง ๆ

\- Self-holding, SET/RST และ Interlock เป็นตรรกะที่มีหน่วยความจำ
เป็นพื้นฐานของการควบคุมแบบลำดับ

\- ต่อเซ็นเซอร์ NPN กับอินพุตแบบ Sink (S/S ต่อ +24 V) และ PNP กับอินพุตแบบ Source
(S/S ต่อ 0 V)

## บทสรุป

PLC เป็นตัวควบคุมดิจิทัลที่ประมวลผลข้อมูลสองสถานะ คือ 0 (OFF) และ 1 (ON)
ผู้ปฏิบัติงานจึงต้องเข้าใจระบบเลขฐานสอง ฐานแปด และฐานสิบหก เนื่องจากหมายเลขอุปกรณ์
X/Y ของ FX5U เป็นเลขฐานแปดและข้อมูลในรีจิสเตอร์เป็นเลขฐานสอง 16 บิต
การทำงานเชิงตรรกะของระบบควบคุมอธิบายได้ด้วยลอจิกเกต ตารางความจริง และพีชคณิตบูลีน
ซึ่งสามารถลดรูปและแปลงเป็นโปรแกรม Ladder ได้โดยตรง กล่าวคือ หน้าสัมผัสต่ออนุกรมคือ
AND ต่อขนานคือ OR และหน้าสัมผัส NC คือ NOT นอกจากนี้ตรรกะที่มีหน่วยความจำ เช่น
Self-holding, SET/RST และ Interlock เป็นพื้นฐานของการควบคุมแบบลำดับในหน่วยต่อไป

## แบบฝึกหัดท้ายหน่วยเรียน

คำชี้แจง: ให้นักศึกษาตอบคำถามต่อไปนี้ให้ถูกต้อง (10 ข้อ)

**1. แปลงเลขฐานสอง 10110101₂ เป็นเลขฐานสิบ ฐานแปด และฐานสิบหก**

<details><summary>เฉลย</summary>

Given/Determine: ฐานสอง 10110101 → ฐานสิบ ฐานแปด ฐานสิบหก

Assumption/ระบบ: ใช้น้ำหนักบิต 2⁷…2⁰ และจัดกลุ่มบิตตามฐาน

สมการ: ค่า = Σ(บิต × 2^ตำแหน่ง)

วิธีทำ: ฐานสิบ = 128 + 32 + 16 + 4 + 1 = 181  ฐานแปด จัดกลุ่ม 3 บิตจากขวา 010|110|101 = 2|6|5 = 265₈ (ตรวจ: 2×64 + 6×8 + 5 = 181)  ฐานสิบหก จัดกลุ่ม 4 บิต 1011|0101 = B|5 = B5₁₆ (ตรวจ: 11×16 + 5 = 181)

ผลเฉลย: 181₁₀ = 265₈ = B5₁₆

</details>

**2. แปลงเลขฐานสิบ 100 เป็นเลขฐานสอง ฐานแปด และฐานสิบหก**

<details><summary>เฉลย</summary>

Given/Determine: 100₁₀ → ฐานสอง ฐานแปด ฐานสิบหก

Assumption/ระบบ: แยกเป็นผลรวมของกำลังของ 2

วิธีทำ: 100 = 64 + 32 + 4 = 2⁶ + 2⁵ + 2² ได้ 1100100₂  ฐานแปด 001|100|100 = 144₈  ฐานสิบหก 0110|0100 = 64₁₆ (ตรวจ: 6×16 + 4 = 100)

ผลเฉลย: 100₁₀ = 1100100₂ = 144₈ = 64₁₆

</details>

**3. จงเขียนตารางความจริงของ Y = A·B̅ + C (3 ตัวแปร)**

<details><summary>เฉลย</summary>

Given/Determine: Y = A·B̅ + C ; หา Y ทุกชุด ABC

Assumption/ระบบ: ตารางมี 2³ = 8 แถว คำนวณ A·B̅ แล้ว OR กับ C

วิธีทำ: ABC = 000→0, 001→1, 010→0, 011→1, 100→1 (A·B̅ = 1), 101→1, 110→0 (A·B̅ = 0 และ C = 0), 111→1

ผลเฉลย: Y = 0,1,0,1,1,1,0,1 ตามลำดับ ABC = 000 ถึง 111

</details>

**4. จงเขียนตารางความจริงของ Y = (A + B)̅ · C และบอกว่าเกิด Y = 1 กี่แถว**

<details><summary>เฉลย</summary>

Given/Determine: Y = NOR(A,B) · C

Assumption/ระบบ: NOR = 1 เมื่อ A = B = 0

วิธีทำ: Y = 1 ต้องมี A = 0, B = 0 และ C = 1 พร้อมกัน จึงมีเพียงแถว ABC = 001 ส่วนอีก 7 แถวเป็น 0 (Y = A̅·B̅·C)

ผลเฉลย: Y = 1 เพียง 1 แถว (ABC = 001)

</details>

**5. จงลดรูป Y = A·B·C + A·B·C̅ + A·B̅·C**

<details><summary>เฉลย</summary>

Given/Determine: ลดรูป Y ให้อยู่ในรูปผลรวมของผลคูณที่น้อยที่สุด

Assumption/ระบบ: ใช้การแจกแจงและกฎ C + C̅ = 1

วิธีทำ: A·B·C + A·B·C̅ = A·B·(C + C̅) = A·B ดังนั้น Y = A·B + A·B̅·C = A·(B + B̅·C) ใช้ B + B̅·C = B + C ได้ Y = A·(B + C)

ผลเฉลย: Y = A·B + A·C (ตรวจด้วย K-map: กลุ่ม AB และ AC)

</details>

**6. ใช้แผนที่คาร์โนห์ลดรูปฟังก์ชัน Y(A,B,C) = Σm(1, 3, 5, 7)**

<details><summary>เฉลย</summary>

Given/Determine: มินเทอม 1,3,5,7 = ABC 001, 011, 101, 111

Assumption/ระบบ: แผนที่ 3 ตัวแปร (A × BC) ใส่ 1 ในช่องมินเทอมที่กำหนด

วิธีทำ: ช่อง 1 ทั้ง 4 อยู่ในคอลัมน์ที่ C = 1 (BC = 01 และ 11) ทั้งสองแถวของ A รวมเป็นกลุ่ม 4 ช่อง ตัวแปร A และ B เปลี่ยนค่าในกลุ่มจึงถูกตัดทิ้ง เหลือ C

ผลเฉลย: Y = C

</details>

**7. จงแปลงสมการ Y0 = (X0 + X1)·X̅2 เป็นแผนภาพ Ladder และรายการคำสั่ง**

<details><summary>เฉลย</summary>

Given/Determine: Y0 = (X0 + X1)·X̅2

Assumption/ระบบ: X0, X1 = สวิตช์ NO; X2 = ตัวแปรกลับค่า ใช้หน้าสัมผัส NC

วิธีทำ: X0 ขนานกับ X1 (OR) แล้วต่ออนุกรมกับหน้าสัมผัส NC ของ X2 (AND NOT) แล้วขับ OUT Y0 รายการคำสั่ง: LD X0 / OR X1 / ANI X2 / OUT Y0 / END

ผลเฉลย: Ladder ตามที่กล่าวและรายการคำสั่งข้างต้น

</details>

**8. ออกแบบวงจรสตาร์ต/สต็อปมอเตอร์ด้วย Self-holding โดย X0 = START (NO), X1 = STOP (NO), X2 = สัญญาณโอเวอร์โหลด (ON เมื่อเกิดโอเวอร์โหลด), Y0 = คอนแทกเตอร์มอเตอร์ ให้ STOP และโอเวอร์โหลดมีลำดับความสำคัญเหนือ START**

<details><summary>เฉลย</summary>

Given/Determine: ออกแบบ Y0 ที่คงสถานะได้ และหยุดเมื่อ X1 หรือ X2 เป็น ON

Assumption/ระบบ: ใช้ Y0 ต่อขนานกับ X0 และต่ออนุกรมด้วย NC ของ X1 และ X2 (หยุดมีลำดับสำคัญกว่า)

สมการ: Y0 = (X0 + Y0)·X̅1·X̅2

วิธีทำ: LD X0 / OR Y0 / ANI X1 / ANI X2 / OUT Y0 / END เมื่อกด START Y0 ติดและล็อกตัวเอง เมื่อ X1 หรือ X2 เป็น ON หน้าสัมผัส NC เปิดวงจร Y0 ดับ แม้กด START ค้างไว้ก็ไม่ติด

ผลเฉลย: Ladder และรายการคำสั่งตามข้างต้น

</details>

**9. จงใช้ทฤษฎีบทของเดอมอร์แกนเขียนฟังก์ชัน NAND Y0 = (X0·X1)̅ เป็น Ladder ที่ใช้เฉพาะหน้าสัมผัส NC และเขียนรายการคำสั่ง**

<details><summary>เฉลย</summary>

Given/Determine: Y0 = (X0·X1)̅

Assumption/ระบบ: ใช้ (A·B)̅ = A̅ + B̅

วิธีทำ: Y0 = X̅0 + X̅1 คือ NC ของ X0 ขนานกับ NC ของ X1 รายการคำสั่ง: LDI X0 / ORI X1 / OUT Y0 / END  ตรวจ: X0 = X1 = 1 → NC ทั้งสองเปิด Y0 = 0 ส่วนกรณีอื่นอย่างน้อยหนึ่งตัวเป็น 0 จึง Y0 = 1

ผลเฉลย: NC ของ X0 ขนาน NC ของ X1 ขับ Y0

</details>

**10. ใช้ FX5U-32MT/ES ต่อเซ็นเซอร์ Proximity แบบ NPN 3 สาย เข้าที่ขั้ว X5 จงตอบ (ก) ต้องต่อขั้ว S/S กับอะไร (ข) FX5U-32M มีอินพุตกี่จุดและหมายเลขสุดท้ายคือใด (ค) เอาต์พุต Y12 เป็นลำดับที่เท่าใดนับจาก Y0 เป็นลำดับที่ 1**

<details><summary>เฉลย</summary>

Given/Determine: FX5U-32MT/ES, เซ็นเซอร์ NPN ที่ X5

Assumption/ระบบ: ES รองรับ Sink/Source ที่ขั้ว S/S ; หมายเลขอุปกรณ์เป็นเลขฐานแปด

วิธีทำ: (ก) NPN คือเอาต์พุต Sink จึงต่ออินพุตแบบ Sink: S/S ต่อ +24 V (ข) FX5U-32M มีอินพุต 16 จุด X0–X7 และ X10–X17 หมายเลขสุดท้ายคือ X17 (ค) Y12₈ = 1×8 + 2 = 10₁₀ นับจาก Y0 = 0 จึงเป็นลำดับที่ 11

ผลเฉลย: (ก) S/S ต่อ +24 V (ข) 16 จุด สุดท้าย X17 (ค) ลำดับที่ 11

</details>
