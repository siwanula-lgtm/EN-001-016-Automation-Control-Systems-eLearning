## จุดประสงค์การสอน

- **4.1 เข้าใจแนวคิดและความแตกต่างของการควบคุมแบบลำดับกับการควบคุมเชิงรวม**
- **4.2 วิเคราะห์ลำดับงานและเขียนแผนภาพลำดับของระบบอัตโนมัติอย่างง่ายได้**
- **4.3 ออกแบบและเขียนโปรแกรมเชิงลำดับด้วย Step relay ได้อย่างถูกต้อง**
- **4.4 เพิ่มวงจรหยุดฉุกเฉิน การรีเซ็ต และโหมดการทำงานให้โปรแกรมได้**
- **จุดประสงค์เชิงพฤติกรรม เมื่อเรียนจบหน่วยนี้แล้ว ผู้เรียนสามารถ**
- **1) อธิบายความแตกต่างระหว่างการควบคุมเชิงรวมและการควบคุมแบบลำดับได้ (LLO4)**
- **2) เขียนแผนภาพลำดับ (Step chart) และ SFC ของงานกระบอกสูบ 2 ตัวได้ (LLO4)**
- **3) กำหนดรีเลย์ขั้นและเขียนเงื่อนไขการเปลี่ยนขั้นด้วย SET/RST ได้ (LLO4)**
- **4) เขียนโปรแกรมเอาต์พุตจากขั้นที่ทำงานอยู่และตรวจสอบด้วยผังเวลา (Timing chart) ได้ (LLO4)**
- **5) วิเคราะห์และแก้ไขข้อผิดพลาดกรณีหลายขั้นทำงานพร้อมกันได้ (LLO4)**
- **6) เพิ่มวงจรหยุดฉุกเฉิน การรีเซ็ต และโหมด Auto/Manual ให้โปรแกรมได้ (LLO4)**
- **7) เขียน ทดสอบโปรแกรมเชิงลำดับด้วย GX Simulator3 พร้อมบันทึกผลได้ (LLO4)**

## 4.1 แนวคิดการควบคุมแบบลำดับ

เครื่องจักรอัตโนมัติจำนวนมากทำงานเป็นขั้นตอนต่อเนื่อง เช่น หนีบชิ้นงาน เจาะ ถอยหัวเจาะ
แล้วคลายชิ้นงาน การควบคุมแบบลำดับ (Sequential Control) จึงต้อง "จำ"
ว่าระบบอยู่ในขั้นใด ต่างจากการควบคุมเชิงรวม (Combinational) ที่ใช้เพียงอินพุตปัจจุบัน
ดังภาพที่ 4.1 หน่วยความจำของขั้นตอนในโปรแกรม PLC ใช้รีเลย์ภายใน M เป็นรีเลย์ขั้น (Step
relay)

![ภาพที่ 4.1 เปรียบเทียบการควบคุมเชิงรวมกับการควบคุมแบบลำดับ](/images/book/a16_image58.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Mitsubishi Electric Corporation (n.d.))

หลักการสำคัญของการควบคุมแบบลำดับ ได้แก่ (1) ในเวลาหนึ่งมีเพียงหนึ่งขั้นที่ทำงาน (2)
การเปลี่ยนขั้นเกิดเมื่อเงื่อนไขการเปลี่ยนขั้น (Transition) เป็นจริง (3)
เอาต์พุตถูกกำหนดจากขั้นที่ทำงานอยู่ และ (4) ต้องมีขั้นเริ่มต้นที่ระบบกลับมารอเสมอ

**ตัวอย่างที่ 4.1** เครื่องเจาะอัตโนมัติมีลำดับ หนีบชิ้นงาน → เจาะลง → เจาะขึ้น →
คลายชิ้นงาน เมื่อกดปุ่ม START ต้องมี 4 ขั้นงานบวกขั้นเริ่มต้น 1 ขั้น รวม 5 ขั้น (M0–M4)
และมีเซนเซอร์ตำแหน่งอย่างน้อย 4 ตัวสำหรับเงื่อนไขการเปลี่ยนขั้น

## 4.2 แผนภาพลำดับและ SFC

ตัวอย่างหลักของหน่วยนี้คือกระบอกสูบสองตัว A และ B ทำลำดับ A+ B+ A- B-
โดยเครื่องหมาย + คือเดินออกและ − คือถอยกลับ เซนเซอร์ที่ใช้คือ a0 (A ถอยสุด) a1 (A
ออกสุด) b0 (B ถอยสุด) b1 (B ออกสุด) แผนภาพลำดับ (Step chart) ในภาพที่ 4.2
แสดงตำแหน่งของกระบอกแต่ละขั้น

![ภาพที่ 4.2 แผนภาพลำดับของกระบอก A และ B ในลำดับ A+ B+ A- B-](/images/book/a16_image59.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Mitsubishi Electric Corporation (n.d.))

แผนภาพ SFC (Sequential Function Chart) ตามมาตรฐาน IEC 61131-3
ช่วยให้เห็นขั้นและเงื่อนไขการเปลี่ยนขั้นชัดเจน ขั้นเริ่มต้นวาดเป็นกรอบสองชั้น ดังภาพที่ 4.3
และแปลงเป็น Ladder ได้โดยตรงด้วยรีเลย์ขั้น M0–M4

![ภาพที่ 4.3 แผนภาพ SFC ของลำดับ A+ B+ A- B- พร้อมเงื่อนไขการเปลี่ยนขั้น](/images/book/a16_image60.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Mitsubishi Electric Corporation (n.d.))

### ตารางที่ 4.2 การกำหนด I/O และรีเลย์ขั้นของตัวอย่าง A+ B+ A- B-

| **อุปกรณ์**      | **ที่อยู่** | **หน้าที่**                            |
|----------------|---------|-------------------------------------|
| START          | X0      | ปุ่มเริ่มรอบการทำงาน                    |
| a0 / a1        | X1 / X2 | เซนเซอร์ A ถอยสุด / ออกสุด             |
| b0 / b1        | X3 / X4 | เซนเซอร์ B ถอยสุด / ออกสุด             |
| E-STOP / RESET | X5 / X6 | หยุดฉุกเฉิน / รีเซ็ตกลับขั้นเริ่มต้น           |
| A+ (วาล์ว A)    | Y0      | ON = กระบอก A เดินออก (วาล์วสปริงคืนตัว) |
| B+ (วาล์ว B)    | Y1      | ON = กระบอก B เดินออก                |
| M0 – M4        | M0 – M4 | รีเลย์ขั้น: ขั้นเริ่มต้น, A+, B+, A-, B-     |

## 4.3 การเขียนโปรแกรมแบบ Step relay ด้วย SET/RST

ขั้นตอนการเขียนมี 3 ส่วน คือ (1) ตั้งขั้นเริ่มต้นด้วย SM402 (2)
เขียนเงื่อนไขการเปลี่ยนขั้นแต่ละขั้น โดย SET ขั้นถัดไปและ RST ขั้นปัจจุบัน และ (3)
เขียนเอาต์พุตจากขั้นที่ทำงาน ภาพที่ 4.4 แสดงขั้นเริ่มต้น ขั้นที่ 1 และขั้นที่ 2

![ภาพที่ 4.4 Step relay: ขั้นเริ่มต้น ขั้นที่ 1 และขั้นที่ 2](/images/book/a16_image61.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Mitsubishi Electric Corporation (n.d.))

ภาพที่ 4.5 แสดงขั้นที่ 3 ขั้นที่ 4 การกลับสู่ขั้นเริ่มต้น และเอาต์พุต เมื่อ A ออกในขั้น 1–2 สมการเอาต์พุตคือ Y0 = M1 + M2 และเมื่อ B ออกในขั้น 2–3 คือ Y1 = M2 + M3

![ภาพที่ 4.6 ขั้นที่ 3 ขั้นที่ 4 การกลับสู่ขั้นเริ่มต้น และเอาต์พุต](/images/book/a16_image62.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Mitsubishi Electric Corporation (n.d.))

**ตัวอย่างที่ 4.2** ถ้า A อยู่ตำแหน่งออก (a1 = 1) แต่ผู้ใช้กด START ขณะ M0 เป็น ON
เงื่อนไข M0·X0·X1·X3 ไม่เป็นจริงเพราะ X1 (a0) = 0 จึงไม่เริ่มรอบ
นี่คือการป้องกันการเริ่มรอบในตำแหน่งที่ไม่ถูกต้อง

![ภาพที่ 4.7 ผังเวลา (Timing chart): ในเวลาหนึ่งมีรีเลย์ขั้นทำงานเพียงหนึ่งตัว](/images/book/a16_image63.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Mitsubishi Electric Corporation (n.d.))

จากผังเวลาจะเห็นว่า M1–M4 ทำงานต่อเนื่องโดยไม่ซ้อนกัน เอาต์พุต Y0 ทำงานตั้งแต่ M1
จนถึงก่อน M3 สิ้นสุด และ Y1 ทำงานตั้งแต่ M2 ถึงสิ้นสุด M3 ตามเงื่อนไขเซนเซอร์ a1 b1 a0
b0 ตามลำดับ

## 4.4 วิธีทางเลือกและข้อผิดพลาดที่พบบ่อย

นอกจาก SET/RST สามารถเขียนโซ่ขั้นตอนด้วย Self-holding ได้
โดยใช้ขั้นถัดไปเป็นเงื่อนไขหยุดของขั้นปัจจุบัน ดังภาพที่ 4.8 วิธีนี้ใช้ OUT ขั้นละหนึ่งแถว ไม่ต้อง
RST แยก แต่ต้องระวังไม่ให้เกิด Double coil และต้องจัดลำดับแถวให้ถูกต้อง

![ภาพที่ 4.8 โซ่ขั้นตอนด้วย Self-holding (ไม่ใช้ SET/RST)](/images/book/a16_image64.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Mitsubishi Electric Corporation (n.d.))

ผลคือเอาต์พุตของขั้นเก่ายังคงอยู่ เช่น Y0 ยังค้างทั้งที่ควรถอยกลับ

![ภาพที่ 4.9 ข้อผิดพลาด: ไม่ RST ขั้นก่อนหน้า ทำให้ M1 และ M2 ทำงานพร้อมกัน](/images/book/a16_image65.png)

### สรุปท้ายใบความรู้

\- การควบคุมแบบลำดับต้องจำขั้นตอนด้วยรีเลย์ขั้น M ในเวลาหนึ่งมีเพียงหนึ่งขั้นทำงาน

\- ขั้นเริ่มต้น M0 ตั้งด้วย SM402 และเริ่มรอบเมื่อ M0·START·ตำแหน่งเริ่มต้นเป็นจริง

\- แต่ละการเปลี่ยนขั้นต้อง SET ขั้นถัดไปและ RST ขั้นก่อนหน้า

\- เอาต์พุตเขียนจากขั้น เช่น Y0 = M1 + M2, Y1 = M2 + M3

\- ต้องมี E-STOP ที่ล้างขั้นและเอาต์พุต RESET ที่ตรวจตำแหน่งเริ่มต้น และโหมดที่ไม่ซ้อนกัน

## บทสรุป

การควบคุมแบบลำดับคือการควบคุมที่ผลลัพธ์ขึ้นกับทั้งสถานะของอินพุตปัจจุบันและ "ขั้นตอน"
ที่ระบบอยู่ ณ ขณะนั้น ผู้ออกแบบเริ่มจากเขียนแผนภาพลำดับ กำหนดรีเลย์ขั้น (Step relay) M0
เป็นขั้นเริ่มต้น และ M1, M2, ... แทนแต่ละขั้น
ขั้นหนึ่งจะเปลี่ยนไปอีกขั้นได้เมื่อเงื่อนไขการเปลี่ยนขั้นเป็นจริง เช่น
เซนเซอร์ตำแหน่งของกระบอกสูบ และต้องล้างขั้นก่อนหน้าเสมอ
เอาต์พุตถูกกำหนดจากขั้นที่ทำงานอยู่ จึงอ่านและแก้ไขโปรแกรมได้ง่าย การเพิ่มวงจรหยุดฉุกเฉิน
โหมดการทำงาน และการรีเซ็ตกลับขั้นเริ่มต้น ทำให้ระบบปลอดภัยและพร้อมใช้งานจริง

Given/Determine: อธิบายความต่างและยกตัวอย่าง

Assumption/ระบบ: เชิงรวมใช้อินพุตปัจจุบัน แบบลำดับมีหน่วยความจำขั้นตอน

สมการ: เชิงรวม: Y = f(X) ; ลำดับ: Y = f(X, ขั้น)

วิธีทำ: เชิงรวม เช่น ไฟบันไดเปิดเมื่อมีคนผ่านเซนเซอร์; ลำดับ เช่น เครื่องเจาะที่ต้องหนีบ → เจาะ → ถอย → คลาย

ผลเฉลย: เชิงรวมไม่ต้องจำขั้น ส่วนแบบลำดับต้องใช้รีเลย์ขั้นเพื่อจำสถานะการทำงาน

</details>

**2. จงเขียนลำดับ Step chart (บรรยาย) ของลำดับ A+ A- B+ B- และกำหนดรีเลย์ขั้น**

<details><summary>เฉลย</summary>

Given/Determine: ลำดับ A+ A- B+ B- ; หาขั้นและรีเลย์ขั้น

Assumption/ระบบ: ขั้นเริ่มต้น M0 และ 4 ขั้นงาน

สมการ: M0 → M1(A+) → M2(A-) → M3(B+) → M4(B-) → M0

วิธีทำ: ขั้น 1: A ออกเมื่อ a1 ไปขั้น 2; ขั้น 2: A กลับเมื่อ a0 ไปขั้น 3; ขั้น 3: B ออกเมื่อ b1 ไปขั้น 4; ขั้น 4: B กลับเมื่อ b0 ไปขั้นเริ่มต้น

ผลเฉลย: Y0 = M1, Y1 = M3 (A ออกเฉพาะขั้น 1, B ออกเฉพาะขั้น 3)

</details>

**3. จากโปรแกรม LD M1 / AND X2 / SET M2 / RST M1 จงอธิบายหน้าที่และเงื่อนไข**

<details><summary>เฉลย</summary>

Given/Determine: IL ที่กำหนด ; อธิบายหน้าที่

Assumption/ระบบ: M1 เป็นขั้นปัจจุบัน X2 = a1

สมการ: M1·X2 = 1 → M2 = 1, M1 = 0

วิธีทำ: เมื่ออยู่ขั้น M1 และ A ออกสุด (X2 = 1) ระบบ SET M2 และ RST M1

ผลเฉลย: เป็นแถวเปลี่ยนขั้นจากขั้นที่ 1 ไปขั้นที่ 2 โดยล้างขั้นเดิม

</details>

**4. ถ้าลืม RST M1 ในแถวเปลี่ยนขั้น M1 → M2 เอาต์พุต Y0 = M1 + M2 และ Y1 = M2 + M3 จะเกิดอะไรขึ้นเมื่อถึงขั้น 3**

<details><summary>เฉลย</summary>

Given/Determine: M1 ไม่ถูกล้าง ; วิเคราะห์ผลที่ขั้น 3

Assumption/ระบบ: M1, M2, M3 ถูก SET ตามลำดับ

สมการ: Y0 = M1 + M2 = 1 (M1 ค้าง)

วิธีทำ: เมื่อถึงขั้น 3 (A ควรถอยกลับ) M1 ยังเป็น 1 จึง Y0 = 1 ทำให้ A ไม่ถอย เซนเซอร์ a0 ไม่เป็นจริง ระบบค้าง

ผลเฉลย: ลำดับค้างที่ขั้น 3 เพราะ A ไม่ถอย แก้โดยเพิ่ม RST M1 ในแถวเปลี่ยนขั้น

</details>

**5. จงเขียนรายการคำสั่งของวงจร SET M0 เมื่อ RUN ครั้งแรก**

<details><summary>เฉลย</summary>

Given/Determine: ตั้งขั้นเริ่มต้นหลัง RUN

Assumption/ระบบ: SM402 ON 1 รอบสแกนหลัง RUN

สมการ: SM402 = 1 → M0 = 1

วิธีทำ: ใช้ LD SM402 แล้ว SET M0

ผลเฉลย: LD SM402 / SET M0

</details>

**6. จงเขียนสมการเอาต์พุต Y0, Y1 สำหรับลำดับ A+ A- B+ B- (M1 = A+, M2 = A-, M3 = B+, M4 = B-) โดยสวิตช์วาล์วสปริงคืนตัว**

<details><summary>เฉลย</summary>

Given/Determine: หา Y0 (A ออก) และ Y1 (B ออก)

Assumption/ระบบ: A ออกเฉพาะขั้น 1, B ออกเฉพาะขั้น 3

สมการ: Y0 = M1 ; Y1 = M3

วิธีทำ: เอาต์พุตเป็น ON เฉพาะขั้นที่ต้องให้กระบอกออก

ผลเฉลย: LD M1 / OUT Y0 / LD M3 / OUT Y1

</details>

**7. จงออกแบบวงจรหยุดฉุกเฉินสำหรับระบบที่มีขั้น M1–M6 และเอาต์พุต Y0–Y3 โดยใช้ X5 เป็น E-STOP**

<details><summary>เฉลย</summary>

Given/Determine: E-STOP X5 ; ล้างขั้น M1–M6 และเอาต์พุต Y0–Y3

Assumption/ระบบ: ใช้ ZRST ช่วงอุปกรณ์ชนิดเดียวกัน

สมการ: X5 = 1 → M1..M6 = 0, Y0..Y3 = 0

วิธีทำ: ใช้ LD X5 ZRST M1 M6 และ LD X5 ZRST Y0 Y3 วางท้ายโปรแกรมเพื่อให้ชนะ SET/OUT ก่อนหน้า

ผลเฉลย: LD X5 / ZRST M1 M6 / LD X5 / ZRST Y0 Y3 / END

</details>

**8. จงให้เหตุผลว่าทำไม RESET ต้องตรวจ a0 และ b0 ก่อน SET M0**

<details><summary>เฉลย</summary>

Given/Determine: อธิบายเหตุผล

Assumption/ระบบ: กระบอกอาจค้างกลางทางหลังหยุดฉุกเฉิน

สมการ: SET M0 = RESET·a0·b0

วิธีทำ: ถ้า SET M0 โดยกระบอกไม่อยู่ตำแหน่งเริ่มต้น การเริ่มรอบใหม่อาจชนหรือทำงานผิดลำดับ

ผลเฉลย: ต้องมั่นใจว่าอุปกรณ์อยู่ตำแหน่งเริ่มต้นก่อนกลับสู่สถานะรอ เพื่อความปลอดภัย

</details>

**9. จงออกแบบการสตาร์ตมอเตอร์ 2 ตัว (Y0, Y1) ให้ Y1 เริ่มได้หลัง Y0 ทำงาน และ STOP (X3, NC จริง) หยุดทั้งสอง**

<details><summary>เฉลย</summary>

Given/Determine: X0 = START1, X1 = START2, X3 = STOP (NC) ; หา IL

Assumption/ระบบ: ใช้ Self-holding และอนุกรม Y0 ในวงจร Y1

สมการ: Y0 = (X0 + Y0)·X3 ; Y1 = (X1 + Y1)·Y0·X3

วิธีทำ: วงจร Y1 ต่ออนุกรมกับหน้าสัมผัส NO ของ Y0 ทำให้ Y1 เริ่มและค้างได้เมื่อ Y0 ทำงาน

ผลเฉลย: LD X0 / OR Y0 / AND X3 / OUT Y0 / LD X1 / OR Y1 / AND Y0 / AND X3 / OUT Y1 / END

</details>

**10. จากลำดับ 5 ขั้น (M0–M4) จงนับจำนวนแถวโปรแกรมทั้งหมดของวิธี SET/RST (ไม่รวม END) สำหรับโปรแกรมตัวอย่าง A+ B+ A- B- พร้อมเอาต์พุต**

<details><summary>เฉลย</summary>

Given/Determine: นับแถวรวมตามภาพ 4.4–4.5

Assumption/ระบบ: แถวเริ่มต้น 1 + เปลี่ยนขั้น 5 + เอาต์พุต 2

สมการ: จำนวนแถว = 1 + 5 + 2

วิธีทำ: แถวเริ่มต้น SM402 1 แถว; เปลี่ยนขั้น M0→M1, M1→M2, M2→M3, M3→M4, M4→M0 รวม 5 แถว; เอาต์พุต Y0, Y1 รวม 2 แถว

ผลเฉลย: รวม 8 แถว (ไม่รวม END)

</details>
