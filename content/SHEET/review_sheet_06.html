EN-001-016 Automation Control Systems · I/O Systems and External Interfacing
สัปดาห์ที่ 6–7 · ท 4 / ป 4 ชม. · CLO2, CLO3
ใบงานปฏิบัติ 1 ใบงาน
📌 1. สาระสำคัญ

ระบบอินพุต/เอาต์พุตเป็นส่วนเชื่อมต่อระหว่าง CPU ของ PLC กับอุปกรณ์สนาม การเลือกอุปกรณ์อินพุตและชนิดเซนเซอร์ NPN/PNP ต้องสอดคล้องกับการต่อขั้ว S/S ของอินพุต การเลือกเอาต์พุตแบบรีเลย์หรือทรานซิสเตอร์ขึ้นกับชนิดและขนาดของโหลด โหลดเหนี่ยวนำต้องมีวงจรป้องกัน การต่อปุ่มหยุดและปุ่มฉุกเฉินแบบ NC ช่วยให้ระบบปลอดภัยเมื่อสายขาด และการตรวจสอบ I/O อย่างเป็นลำดับช่วยให้ค้นหาข้อผิดพลาดได้รวดเร็ว

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • 6.1 เข้าใจโครงสร้างระบบอินพุต/เอาต์พุตของ PLC
  • 6.2 เลือกอุปกรณ์อินพุตและเอาต์พุตให้เหมาะสมกับงาน
  • 6.3 ต่อวงจรเชื่อมต่อ PLC กับเซนเซอร์และโหลดได้อย่างปลอดภัย
  • 6.4 ตรวจสอบและแก้ไขข้อผิดพลาดของ I/O ได้
🧩 3. หัวข้อเนื้อหาในหน่วย
  • 6.1 โครงสร้างระบบอินพุต/เอาต์พุต
  • 6.2 อุปกรณ์อินพุตและการเลือกเซนเซอร์
  • 6.3 เซนเซอร์ NPN/PNP และการต่ออินพุต
  • 6.4 เอาต์พุตและการต่อโหลด
  • 6.5 วงจรควบคุมมอเตอร์ Fail-safe และปุ่มหยุดฉุกเฉิน
  • 6.6 การนับด้วยเซนเซอร์ รายการ I/O และการตรวจสอบข้อผิดพลาด
📝 4. บทสรุป

ระบบอินพุต/เอาต์พุตเป็นส่วนเชื่อมต่อระหว่าง CPU ของ PLC กับอุปกรณ์สนาม การเลือกอุปกรณ์อินพุตและชนิดเซนเซอร์ NPN/PNP ต้องสอดคล้องกับการต่อขั้ว S/S ของอินพุต การเลือกเอาต์พุตแบบรีเลย์หรือทรานซิสเตอร์ขึ้นกับชนิดและขนาดของโหลด โหลดเหนี่ยวนำต้องมีวงจรป้องกัน การต่อปุ่มหยุดและปุ่มฉุกเฉินแบบ NC ช่วยให้ระบบปลอดภัยเมื่อสายขาด และการตรวจสอบ I/O อย่างเป็นลำดับช่วยให้ค้นหาข้อผิดพลาดได้รวดเร็ว

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • จงยกตัวอย่างอุปกรณ์อินพุต 3 ชนิดและเอาต์พุต 3 ชนิดของสายพานลำเลียง
  • ชิ้นงานเป็นเหล็กและพลาสติกปะปนกัน ต้องการแยกเฉพาะเหล็ก ควรเลือกเซนเซอร์ใด เพราะเหตุใด
  • เซนเซอร์ NPN ต่อเข้าอินพุตของ PLC ต้องต่อ S/S อย่างไร (ตามตารางในหน่วย) และถ้าต่อผิดจะเกิดอะไร
  • จงเปรียบเทียบเอาต์พุตรีเลย์กับทรานซิสเตอร์ 3 ประเด็น
  • คอยล์คอนแทกเตอร์ 24 VDC กินกระแส 200 mA ถ้าเอาต์พุตรับได้ 0.5 A ต่อจุด ต่อตรงได้หรือไม่ และต้องเพิ่มอุปกรณ์ใด
  • จงเขียน IL ของวงจรสตาร์ต/สต็อป Y0 เมื่อ START = X0 (NO), STOP = X1 (NC) , OL = X2 (NC)
⚠️ ข้อควรระวังด้านความปลอดภัย (ใบงานปฏิบัติ)
  • ข้อควรระวังด้านความปลอดภัย: ตัดไฟก่อนต่อวงจรทุกครั้ง ตรวจขั้ว 24 V/0 V
