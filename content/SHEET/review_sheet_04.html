EN-001-016 Automation Control Systems · Sequential Control Programming
สัปดาห์ที่ 4 · ท 2 / ป 2 ชม. · CLO3
ใบงานปฏิบัติ 1 ใบงาน
📌 1. สาระสำคัญ

การควบคุมแบบลำดับคือการควบคุมที่ผลลัพธ์ขึ้นกับทั้งสถานะของอินพุตปัจจุบันและ "ขั้นตอน" ที่ระบบอยู่ ณ ขณะนั้น ผู้ออกแบบเริ่มจากเขียนแผนภาพลำดับ กำหนดรีเลย์ขั้น (Step relay) M0 เป็นขั้นเริ่มต้น และ M1, M2, ... แทนแต่ละขั้น ขั้นหนึ่งจะเปลี่ยนไปอีกขั้นได้เมื่อเงื่อนไขการเปลี่ยนขั้นเป็นจริง เช่น เซนเซอร์ตำแหน่งของกระบอกสูบ และต้องล้างขั้นก่อนหน้าเสมอ เอาต์พุตถูกกำหนดจากขั้นที่ทำงานอยู่ จึงอ่านและแก้ไขโปรแกรมได้ง่าย การเพิ่มวงจรหยุดฉุกเฉิน โหมดการทำงาน และการรีเซ็ตกลับขั้นเริ่มต้น ทำให้ระบบปลอดภัยและพร้อมใช้งานจริง

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • 4.1 เข้าใจแนวคิดและความแตกต่างของการควบคุมแบบลำดับกับการควบคุมเชิงรวม
  • 4.2 วิเคราะห์ลำดับงานและเขียนแผนภาพลำดับของระบบอัตโนมัติอย่างง่ายได้
  • 4.3 ออกแบบและเขียนโปรแกรมเชิงลำดับด้วย Step relay ได้อย่างถูกต้อง
  • 4.4 เพิ่มวงจรหยุดฉุกเฉิน การรีเซ็ต และโหมดการทำงานให้โปรแกรมได้
🧩 3. หัวข้อเนื้อหาในหน่วย
  • 4.1 แนวคิดการควบคุมแบบลำดับ
  • 4.2 แผนภาพลำดับและ SFC
  • 4.3 การเขียนโปรแกรมแบบ Step relay ด้วย SET/RST
  • 4.4 วิธีทางเลือกและข้อผิดพลาดที่พบบ่อย
  • 4.5 การหยุดฉุกเฉิน การรีเซ็ต โหมด และการทำงานต่อเนื่อง
  • 4.6 การสตาร์ตมอเตอร์ตามลำดับและขั้นตอนการออกแบบ
📝 4. บทสรุป

การควบคุมแบบลำดับคือการควบคุมที่ผลลัพธ์ขึ้นกับทั้งสถานะของอินพุตปัจจุบันและ "ขั้นตอน" ที่ระบบอยู่ ณ ขณะนั้น ผู้ออกแบบเริ่มจากเขียนแผนภาพลำดับ กำหนดรีเลย์ขั้น (Step relay) M0 เป็นขั้นเริ่มต้น และ M1, M2, ... แทนแต่ละขั้น ขั้นหนึ่งจะเปลี่ยนไปอีกขั้นได้เมื่อเงื่อนไขการเปลี่ยนขั้นเป็นจริง เช่น เซนเซอร์ตำแหน่งของกระบอกสูบ และต้องล้างขั้นก่อนหน้าเสมอ เอาต์พุตถูกกำหนดจากขั้นที่ทำงานอยู่ จึงอ่านและแก้ไขโปรแกรมได้ง่าย การเพิ่มวงจรหยุดฉุกเฉิน โหมดการทำงาน และการรีเซ็ตกลับขั้นเริ่มต้น ทำให้ระบบปลอดภัยและพร้อมใช้งานจริง

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • จงบอกความแตกต่างระหว่างการควบคุมเชิงรวมและแบบลำดับพร้อมยกตัวอย่างอย่างละ 1 ระบบ
  • จงเขียนลำดับ Step chart (บรรยาย) ของลำดับ A+ A- B+ B- และกำหนดรีเลย์ขั้น
  • จากโปรแกรม LD M1 / AND X2 / SET M2 / RST M1 จงอธิบายหน้าที่และเงื่อนไข
  • ถ้าลืม RST M1 ในแถวเปลี่ยนขั้น M1 → M2 เอาต์พุต Y0 = M1 + M2 และ Y1 = M2 + M3 จะเกิดอะไรขึ้นเมื่อถึงขั้น 3
  • จงเขียนรายการคำสั่งของวงจร SET M0 เมื่อ RUN ครั้งแรก
  • จงเขียนสมการเอาต์พุต Y0, Y1 สำหรับลำดับ A+ A- B+ B- (M1 = A+, M2 = A-, M3 = B+, M4 = B-) …
⚠️ ข้อควรระวังด้านความปลอดภัย (ใบงานปฏิบัติ)
  • ข้อควรระวังด้านความปลอดภัย: ตัดไฟก่อนต่อวงจรทุกครั้ง ตรวจขั้ว 24 V/0 V
  • เสนอวิธีเพิ่มความปลอดภัยของวงจร E-STOP ในการต่อวงจรจริง (เช่น ชนิดหน้าสัมผัสที่ใช้)
  • 2. ตัวอย่างเครื่องจักรที่กลุ่มเลือกพร้อม Step chart และข้อควรระวังด้านความปลอดภัยของระบบ
🔧 6. เชื่อมโยงกับใบงานปฏิบัติหน่วยเรียนที่ 4

การเขียนโปรแกรมควบคุมกระบอกสูบ 2 ตัว A+ B+ A- B- ด้วย Step relay และวงจรหยุดฉุกเฉิน
