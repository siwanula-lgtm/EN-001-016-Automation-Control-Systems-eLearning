📌 1. สาระสำคัญ

คำสั่งพื้นฐานของ PLC คือชุดคำสั่งที่ใช้แปลงตรรกะควบคุมเป็นโปรแกรม Ladder และรายการคำสั่ง (Instruction List) ได้แก่ LD, LDI, AND, ANI, OR, ORI, OUT สำหรับเงื่อนไขและเอาต์พุต ANB, ORB, INV และ MPS/MRD/MPP สำหรับจัดการบล็อกและสาขา SET, RST, ZRST สำหรับเก็บและล้างสถานะ และ PLS, PLF สำหรับตรวจจับขอบสัญญาณ PLC ประมวลผลโปรแกรมจากบนลงล่างและซ้ายไปขวาเป็นรอบสแกน อุปกรณ์ที่ถูกเขียนค่าท้ายสุดในรอบสแกนจะเป็นค่าที่มีผล ผู้ปฏิบัติงานจึงต้องเข้าใจลำดับแถวเพื่อออกแบบวงจร Self-holding, Interlock และ Toggle ให้ทำงานถูกต้องและปลอดภัย

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • 3.1 เข้าใจภาษา Ladder อุปกรณ์ และลำดับการประมวลผลของ PLC
  • 3.2 ใช้คำสั่งพื้นฐานของ PLC เขียนโปรแกรมควบคุมได้ถูกต้อง
  • 3.3 เข้าใจและออกแบบวงจร Self-holding, Interlock และ Toggle ได้
  • 3.4 เขียน ทดสอบ และตรวจสอบโปรแกรมด้วย GX Works3 / GX Simulator3 ได้
🧩 3. หัวข้อเนื้อหาในหน่วย
  • 3.1 ภาษา Ladder อุปกรณ์ และการประมวลผลโปรแกรม
  • 3.2 คำสั่ง LD, LDI, AND, ANI, OR, ORI และ OUT
  • 3.3 คำสั่งรวมบล็อกและแยกสาขา: ANB, ORB, INV, MPS/MRD/MPP
  • 3.4 คำสั่ง SET, RST และ ZRST
  • 3.5 คำสั่งตรวจจับขอบสัญญาณ PLS และ PLF
  • 3.6 Self-holding, Interlock, Toggle และ Double coil
📝 4. บทสรุป

คำสั่งพื้นฐานของ PLC คือชุดคำสั่งที่ใช้แปลงตรรกะควบคุมเป็นโปรแกรม Ladder และรายการคำสั่ง (Instruction List) ได้แก่ LD, LDI, AND, ANI, OR, ORI, OUT สำหรับเงื่อนไขและเอาต์พุต ANB, ORB, INV และ MPS/MRD/MPP สำหรับจัดการบล็อกและสาขา SET, RST, ZRST สำหรับเก็บและล้างสถานะ และ PLS, PLF สำหรับตรวจจับขอบสัญญาณ PLC ประมวลผลโปรแกรมจากบนลงล่างและซ้ายไปขวาเป็นรอบสแกน อุปกรณ์ที่ถูกเขียนค่าท้ายสุดในรอบสแกนจะเป็นค่าที่มีผล ผู้ปฏิบัติงานจึงต้องเข้าใจลำดับแถวเพื่อออกแบบวงจร Self-holding, Interlock และ Toggle ให้ทำงานถูกต้องและปลอดภัย

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • เขียนรายการคำสั่งของ Y0 = (X0 + X1) · X̅2 · X3 (X0, X1 ต่อขนานกัน)
  • จากรายการคำสั่ง LD X0 / AND X1 / LD X2 / AND X3 / ORB / OUT Y0 จงเขียนนิพจน์บูลีนของ Y0
  • จงเขียนรายการคำสั่งและอธิบาย Ladder ของ Y1 = (X0 + X1)·(X2 + X3)
  • จงเขียนโปรแกรมของเกต NAND สองอินพุต Y0 = (X0·X1)̅ โดยใช้ INV และโดยใช้เดอมอร์แกน (หน้าสัมผัส NC)
  • มอเตอร์ใช้ START (X0, NO), STOP (X1, ต่อแบบ NC), โอเวอร์โหลด (X2, ต่อแบบ NC) ออกแบบ Self-holding ขับ Y0 แบบ …
  • โปรแกรมมีแถว LD X0 / SET Y1 และแถว LD X1 / RST Y1 (แถว RST อยู่หลัง) จงบอกค่า Y1 เมื่อ (X0,X1) = (1,0), …
⚠️ ข้อควรระวังด้านความปลอดภัย (ใบงานปฏิบัติ)
  • ข้อควรระวังด้านความปลอดภัย: ตัดไฟก่อนต่อวงจรทุกครั้ง ตรวจขั้ว 24 V/0 V
  • และข้อดีด้านความปลอดภัยคืออะไร
  • หัวข้ออภิปราย: "เหตุใดงานที่เกี่ยวข้องกับความปลอดภัยจึงควรใช้ Stop priority และปุ่ม
