EN-001-016 Automation Control Systems · PLC Communication and Networks
สัปดาห์ที่ 9 · ท 2 / ป 2 ชม. · CLO2
ใบงานปฏิบัติ 1 ใบงาน
📌 1. สาระสำคัญ

การสื่อสารทำให้ PLC แลกเปลี่ยนข้อมูลกับพีซี HMI อินเวอร์เตอร์ และ PLC เครื่องอื่นได้ โดยต้องกำหนดมาตรฐานทางกายภาพ พารามิเตอร์ (เช่น IP address) และโปรโตคอลให้ตรงกันทั้งสองฝั่ง การแลกเปลี่ยนข้อมูลในโปรแกรมอาศัยแผนที่รีจิสเตอร์ที่ตกลงร่วมกัน และต้องตรวจสอบสถานะการสื่อสารเพื่อให้ระบบทำงานได้อย่างปลอดภัย

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • 7.1 เข้าใจหลักการและมาตรฐานการสื่อสารข้อมูลของ PLC
  • 7.2 กำหนดพารามิเตอร์เครือข่ายได้ถูกต้อง
  • 7.3 ออกแบบแผนที่ข้อมูลและเขียนโปรแกรมแลกเปลี่ยนข้อมูลได้
  • 7.4 ตรวจสอบและแก้ไขปัญหาการสื่อสารเบื้องต้นได้
🧩 3. หัวข้อเนื้อหาในหน่วย
  • 7.1 หลักการสื่อสารข้อมูลและมาตรฐานสัญญาณ
  • 7.2 เครือข่าย PLC และอีเทอร์เน็ต
  • 7.3 โปรโตคอล Modbus และ Master-Slave
  • 7.4 การแลกเปลี่ยนข้อมูลด้วยรีจิสเตอร์
  • 7.5 การตรวจสอบข้อผิดพลาดของการสื่อสาร
📝 4. บทสรุป

การสื่อสารทำให้ PLC แลกเปลี่ยนข้อมูลกับพีซี HMI อินเวอร์เตอร์ และ PLC เครื่องอื่นได้ โดยต้องกำหนดมาตรฐานทางกายภาพ พารามิเตอร์ (เช่น IP address) และโปรโตคอลให้ตรงกันทั้งสองฝั่ง การแลกเปลี่ยนข้อมูลในโปรแกรมอาศัยแผนที่รีจิสเตอร์ที่ตกลงร่วมกัน และต้องตรวจสอบสถานะการสื่อสารเพื่อให้ระบบทำงานได้อย่างปลอดภัย

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • จงเปรียบเทียบ RS-232C และ RS-485 3 ประเด็น
  • อุปกรณ์ 3 เครื่องมี IP 192.168.1.5, 192.168.1.9, 192.168.2.9 (mask 255.255.255.0) เครื่องใดอยู่คนละเครือข่าย
  • เหตุใด IP address จึงต้องไม่ซ้ำกัน
  • จงอธิบายหน้าที่ของ 4 ฟิลด์ในเฟรม Modbus RTU
  • จงเขียน IL เมื่อกด X0 ให้ D1 = 1 และกด X1 ให้ D1 = 0
  • ถ้า D10 = 7 วงจร LD>= D10 K10 → OUT Y1 ทำงานหรือไม่
⚠️ ข้อควรระวังด้านความปลอดภัย (ใบงานปฏิบัติ)
  • ข้อควรระวังด้านความปลอดภัย: ตัดไฟก่อนต่อวงจรทุกครั้ง ตรวจขั้ว 24 V/0 V
  • เสนอแนวปฏิบัติด้านความปลอดภัยของเครือข่ายอย่างน้อย 2 ข้อ
  • 2. เครือข่ายหรือระบบสื่อสารที่กลุ่มพบ และข้อสังเกตด้านความปลอดภัย
